# Codex Review

This folder contains Codex-authored, repo-grounded review artifacts. These files
are reports only; they are not product code.

## Reports

- [Review index](INDEX.md)

Currentness rule: each report is valid only for the commit and dirty files named
inside that report. Rerun the relevant pass after source edits before treating an
older finding as current.

Note: local engineering quality-pass reports may exist under
`codex_review/quality-pass/`, but that folder is ignored unless a specific report
is intentionally force-added.
