# Matter Workbench v1.0.0-beta.65

Date: 2026-06-26

This is a Beta 3 read-only source-removal impact preview release. It exposes a
backend preview endpoint that answers what would be affected if a source file
were removed from the active record, without performing any mutation and without
adding UI.


The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.64

Read-only impact preview endpoint:

- adds `GET /api/source-removal-impact-preview`;
- accepts `fileId` / `file_id` plus the normal explicit `matter` query;
- uses DB-native Matter Context packets in runtime DB mode;
- uses local Matter Context packets in filesystem mode;
- returns `source-removal-impact-preview/v1`;
- requires a valid `FILE-NNNN` id;
- reports whether the source is active/removable;
- reports affected active context counts and artifact families;
- keeps physical deletion false and requires future reason/idempotency for any
  write path.

Safety posture:

- no source-removal write route is added;
- no lawyer-facing remove/delete UI is added;
- no file bytes or artifacts are changed;
- no Matter Log event is written by preview;
- no restore/quarantine workflow is added;
- no physical purge behavior is added.
