# Matter Workbench v1.0.0-beta.56

Date: 2026-06-26

This is a Beta 3 Matter Events foundation release. It adds the durable
`matter_events` storage layer needed for long-term canonical Matter Log events,
without adding file removal or any destructive matter mutation.

## Release Position

Release as:

```text
v1.0.0-beta.56
```

Tag target / deployed commit:

```text
b263758 Add durable matter events foundation
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.55

Matter events foundation:

- adds migration `020_matter_events`;
- creates tenant-scoped `matter_events` with RLS, idempotency keys, matter id,
  denormalized matter name, actor/source JSON, object JSON, payload JSON, and
  query indexes;
- adds `services/runtime-db-matter-events-service.mjs` for Postgres append/list;
- adds `services/matter-events-service.mjs` as an append-only local JSONL
  fallback for filesystem mode;
- wires the server to use Postgres matter events in runtime DB mode and local
  JSONL otherwise;
- updates Matter Log projection to merge canonical `matter_events` entries ahead
  of legacy job/run projections when events exist;
- updates Activity typing/rendering so canonical event rows are labeled
  `canonical event` instead of `projection`.

Safety posture:

- blocks `source_file.deleted` / `source_document.deleted` event vocabulary;
- keeps file removal, tombstones, restore/quarantine, and artifact-currentness
  projection out of this release;
- documents that no production mutation is transaction-coupled to
  `matter_events` yet. The next safe step is a low-risk `custom_skill.created`
  append at the strongest available Skill Factory/store boundary.

## Not Promised

This release does not add file removal, tombstones, restore/quarantine, artifact
currentness projection, outbox publishing, Kafka/broker integration, or a
transaction-coupled production mutation event. It creates the durable storage and
projection foundation only.

Conversation memory and Copilot receipts remain non-evidence.
