This is a supervised beta Research release that preserves statute corpus/provenance metadata through the Workbench Research answer and records the sidecar deployment automation in the released app source.

## Included Since beta.121

- Adds first-class private VM automation for the loopback Legal Source Sidecar/statutes services:

  ```bash
  npm run private-vm:legal-source-sidecar-deploy -- \
    --host <vm> \
    --user aks \
    --sidecar-root /home/aks/matter-workbench-sidecars \
    --legal-source-dir /Users/aksingh/legal-source-service \
    --statutes-dir /Users/aksingh/statutes \
    --configure-workbench-env
  ```

- The sidecar deploy helper syncs sidecar/statutes source, installs user-local Node 22, builds the statutes DB with `npm run build:corpus`, installs `mwb-statutes.service` and `mwb-legal-source.service`, restarts them, and health-checks loopback services.
- The helper rejects password/token/secret command-line arguments and leaves sidecar web/Exa mode disabled by default.
- Research now preserves bounded sidecar statute metadata on validated `public_sources[].metadata`, including slug, section, act, act number, heading, corpus fingerprint, build time, last refreshed time, and provenance summary.
- Research now records unique statute corpus fingerprints under `research.corpus_fingerprints` so Copilot interaction receipts can identify the exact corpus used for a statutory answer.
- Frontend Research public-source types now allow the bounded metadata object without changing the concise lawyer-facing source display.
- Updated statutes/sidecar docs to prefer `npm run build:corpus` for the real statutes corpus.

## Not Promised

This release does not make statutes Research lawyer-verified or filing-ready. It does not claim the corpus is complete or current beyond the reported statutes health/corpus fingerprint. It does not enable sidecar web/Exa mode on the beta VM. It does not add a direct statute browser, statutory cross-reference UI, or durable research memo artifact.

Research remains chat-only by default. The answer caveat remains required:

```text
_Verify authorities before relying or filing._
```
