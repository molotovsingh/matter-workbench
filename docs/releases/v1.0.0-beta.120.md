## Included Since beta.119

- Explicitly standardizes rendered Markdown body text at a consistent size.
- Gives Markdown paragraphs and list items the same foreground color and line height.
- Overrides inherited generic editor paragraph styling inside Markdown previews.
- Keeps headings, code, tables, page frame, justification behavior, and the specialized Case Timeline/List of Dates preview unchanged.

## Behavior

Generic rendered Markdown documents now use a consistent body typography baseline. Paragraphs and list items no longer inherit mismatched editor paragraph color, max-width, or line-height rules that could make adjacent blocks appear to have different sizes.

## Operator Notes

Use `v1.0.0-beta.120` for supervised testing. If text still appears visually inconsistent, compare heading, table, inline-code, paragraph, and list styles separately; only body paragraphs/list items are intended to share this normalized baseline.
