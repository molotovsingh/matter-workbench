# Matter Workbench v1.0.0-beta.67

Date: 2026-06-27

Codename: **Confirmation Drum**

This is a Beta 3 archive UX hotfix. It makes the Archive action visibly respond on first click by opening an inline confirmation panel before any matter is archived.

## Release Position

Release as:

```text
v1.0.0-beta.67
```

Tag target / deployed commit:

```text
73f29b6 Make matter archive confirmation visible
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.66

Archive confirmation UX:

- first click on `Archive` now opens a visible inline panel;
- the panel explains that archiving closes the matter from active work;
- the panel explicitly says source files, generated artifacts, file IDs, and history are not deleted;
- the panel explains that the matter can be reopened from `All matters → Archived`;
- archiving now requires a clear `Confirm archive` click inside the panel;
- `Cancel` dismisses the panel without changing matter state.
