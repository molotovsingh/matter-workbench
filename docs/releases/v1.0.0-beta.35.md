# Matter Workbench v1.0.0-beta.35

Date: 2026-06-24

Codename: **Railwright**

This is a Beta 3 Matter Assistant rail UX hardening release. It keeps beta.34
Copilot thread-helper behavior and makes the assistant rail resizable while
simplifying the header so Ask / Research / Skill have more usable room.

## Release Position

Release as:

```text
v1.0.0-beta.35
```

Tag target / deployed commit:

```text
20ccabe Update UI hardening assistant shell check
```

The tag points to the exact code installed on the DigitalOcean beta VM.

Meaning:

- Beta 3 remains the accepted private-cloud beta line;
- the deployed product remains the React-only private beta with runtime DB
  storage;
- the right Matter Assistant rail can now be resized by dragging its left edge;
- the rail width is a browser-local preference;
- double-clicking the resize handle resets the width;
- the assistant header is compact (`Matter Assistant`, `New`, operator-visible
  model selector) and no longer uses the large `What do you need?` headline;
- command routing, Ask / Research behavior, receipts, source validation, and
  evidence rules are unchanged.

## Included Since beta.34

Matter Assistant rail UX:

- added a resize handle on the left edge of the Matter Assistant rail;
- persisted rail width in browser `localStorage`;
- clamped width to safe viewport bounds;
- hid the resize handle in single-column responsive layouts;
- simplified the assistant header copy;
- documented assistant rail hardening in the navigation-shell decision note.

Validation hardening:

- added tests proving the resize handle, browser-local width key, compact header,
  and updated UI-hardening home-shell check;
- updated the rendered UI hardening script to look for the compact assistant
  header instead of the retired headline.

## Not Promised

This release does not add new Copilot behavior, durable memory, receipt
analytics, or new Research semantics. It is a visual/interaction hardening slice
for the Matter Assistant rail.

## Operator Notes

If the assistant rail looks too narrow or too wide, drag its left edge or
double-click the resize handle to reset. Width is stored only in the browser.
If rollback is needed, deploy the recorded rollback candidate `01cec10`.
