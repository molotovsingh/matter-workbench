# Matter Workbench v1.0.0-beta.88

Date: 2026-06-29

Codename: **Policy Spine**

This is an internal model-policy refactor on top of beta.87. It moves Settings-visible AI task status metadata into `shared/model-policy.mjs` so provider/model display rows use the same route source of truth as runtime provider policy.


## Included Since beta.87

- `shared/model-policy.mjs` now exports `listAiTaskStatusMetadata()`.
- `services/ai-settings-service.mjs` no longer carries a separate `AI_TASK_STATUS` list.
- Settings-visible AI task labels and OpenAI/OpenRouter model env keys are now derived from model policy task definitions.
- A model-policy regression test locks the displayed task metadata and env-key mapping.
