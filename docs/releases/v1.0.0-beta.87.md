Date: 2026-06-29

Codename: **Provider Spine**

This is an internal provider-boundary refactor on top of beta.86. It removes the duplicate Matter Copilot settings-check HTTP path and routes Copilot model checks through the shared AI provider service.

## Included Since beta.86

- Matter Copilot settings checks now use `createAiProviderService(...).invoke()` instead of bespoke OpenAI/OpenRouter ping code.
- Provider choice errors embedded in successful HTTP responses preserve the actual provider choice message instead of collapsing to `Provider returned 200`.
- Provider choice errors embedded in HTTP 200 responses now map to provider bad-output status `502`.
- Raw transport failures during AI settings checks still redact submitted API keys without being converted into user-facing provider language.
- The UI hardening Copilot tier check now waits for async backend-provided preset options.
