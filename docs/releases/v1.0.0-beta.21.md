# Matter Workbench v1.0.0-beta.21

Date: 2026-06-18

This is the Beta 3 successful-slow feedback triage marker. It keeps the
beta.20 misfiled-feedback router and adds one conservative deterministic rule:
reports that explicitly say an operation succeeded but took time are treated as
performance context, not as unresolved runtime failures.

## Release Position

Release as:

```text
v1.0.0-beta.21
```

Tag target / deployed commit:

```text
8f8636c Route successful slow feedback to watch
```

Branch documentation commits after `8f8636c` record this release note and
current-release pointers only; they do not change the hosted product behavior
covered by the beta.21 tag.

Meaning:

- the deployed private beta remains the React-only product UI;
- runtime DB storage remains the accepted hosted-beta path;
- DigitalOcean deployment uses the repeatable `private-vm:rsync-deploy` flow;
- runtime and mothership services are expected to be active;
- the operator feedback-triage loop can review, filter, mark, audit, and
  deterministically re-route obvious product/UX/note/successful-slow feedback
  without changing tester-facing intake;
- no provider calls are required for feedback triage;
- credit metering remains shadow/report-only, with no billing or enforcement;
- no public SaaS signup, self-service billing, or unsupervised legal reliance is
  implied.

## Included Since beta.20

Operator-side feedback-triage routing improvement:

- bug-channel reports that explicitly say the operation was successful, but
  slow, route to `operator_note` / `watch`;
- unresolved slow reports such as “Taking lot of time” remain in the
  `bug` / `investigate` evidence queue;
- concrete product-control failures, legal-quality concerns, preparation
  failures, auth issues, and unsupported-citation bugs remain on their existing
  deterministic paths;
- report/status audit metadata from beta.19 remains intact.

The operator-only triage design is documented in
[`docs/future-design-decisions/feedback-triage-router-plan.md`](../future-design-decisions/feedback-triage-router-plan.md).

## Not Promised

reset, unsupervised legal reliance, external object storage, hard credit
enforcement, automated AI feedback classification, or a multi-region production
posture. It is a private-cloud beta for trusted testers and supervised
operators.
