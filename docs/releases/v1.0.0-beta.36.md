# Matter Workbench v1.0.0-beta.36

Date: 2026-06-24

This is a Beta 3 Matter Copilot model-selector release. It keeps beta.35
assistant-rail hardening and adds a GPT 5.5 Copilot preset for operator use.

## Release Position

Release as:

```text
v1.0.0-beta.36
```

Tag target / deployed commit:

```text
1a34483 Add GPT 5.5 Copilot preset
```

The tag points to the exact code installed on the DigitalOcean beta VM.

Meaning:

- Beta 3 remains the accepted private-cloud beta line;
- the deployed product remains the React-only private beta with runtime DB
  storage;
- Matter Copilot now exposes a `Highest` preset using OpenRouter model
  `openai/gpt-5.5`;
- the VM Matter Copilot route has been switched to `openrouter / openai/gpt-5.5`;
- durable skills, List of Dates, source labels, and other governed routes remain
  app-policy controlled and are not changed by the Copilot selector.

## Not Promised

The `Highest` preset affects transient Matter Copilot answers only. It does not
change model policy for List of Dates, source labels, custom skill authoring,
custom skill runs, or Research synthesis.

## Operator Notes

Use Settings → Matter Copilot → `Highest` to select GPT 5.5. The settings save
path pings the model before accepting it. If rollback is needed, deploy the
recorded rollback candidate `20ccabe`.
