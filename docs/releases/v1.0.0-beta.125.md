# Matter Workbench v1.0.0-beta.125

Date: 2026-07-09

Codename: **Row Anchor**

This was a supervised beta MW List of Dates quality patch. It was deployed briefly and immediately superseded by v1.0.0-beta.126 after the stricter row-level prompt needed a larger provider output budget for large matters.

## Included Since beta.124

- Tightened MW List of Dates row selection so each generated MW List row must cite exactly one Case Timeline row.
- Added validation to reject broad date-range summary rows that collapse many Case Timeline dates into a single MW List row.
- Added a large-matter guard so a substantial Case Timeline cannot become a four-row executive summary.
- Rendered source labels in the Markdown table with readable separators instead of HTML `<br>` markers that the safe Markdown viewer skips.
- Added regression coverage for grouped-date rejection and hidden internal handles.

## Behavior

The intended behavior was to keep MW List of Dates as a row-level Case Timeline transformation rather than a high-level narrative summary. In particular, rows such as “transaction opened and then many later payments/demands happened” are rejected when they cite multiple dated Case Timeline rows.

This release was superseded because a live rerun on a large matter returned truncated provider JSON under the previous output budget after the prompt requested 12–25 individual rows.
