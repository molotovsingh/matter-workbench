# Matter Workbench v1.0.0-beta.59

Date: 2026-06-26

This is a Beta 3 active-context hardening release. It prevents stale generated
Library artifact summaries from reintroducing suppressed source citations into
Matter Context, without adding file removal UI or source-removal writes.

Release as:

```text
v1.0.0-beta.59

```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.58

Generated artifact suppression in Matter Context:

- passes the active source suppression index into local Matter Context Library
  artifact summaries;
- filters Source Index summary counts down to active sources;
- filters List of Dates JSON entries that cite suppressed `FILE-NNNN` ids;
- skips List of Dates Markdown summaries when the markdown cites a suppressed
  `FILE-NNNN` id;
- applies the same generated-artifact suppression behavior to runtime DB Matter
  Context packets using inactive File Register rows;
- exposes optional `source_count_total`, `sources_suppressed`,
  `entry_count_total`, and `entries_suppressed` counters in the frontend type
  contract.

Safety posture:

- no source-removal write path is added;
- no lawyer-facing remove/delete UI is added;
- no physical purge behavior is added;
- suppressed generated artifact entries are not deleted; they simply do not feed
  active context/read models;
- future source-file removal remains blocked behind canonical source-custody
  events, atomic tombstone/status writes, active source-set currentness, restore
  and quarantine semantics, and privilege-safe Matter Log summaries.

## Not Promised

This release does not add file removal, source-removal writes, restore,
quarantine workflows, artifact currentness projection, source-custody mutation
events, physical deletion, outbox publishing, or Kafka/broker integration.

Conversation memory and Copilot receipts remain non-evidence.

## Operator Notes

No new user action is required. Existing matters without a suppression manifest
or inactive File Register rows behave as before. If a matter contains suppressed
sources, Matter Context now also filters stale generated Library summaries before
they reach Copilot/search/custom-skill context. If rollback is needed, deploy
`d86a2ec`.
