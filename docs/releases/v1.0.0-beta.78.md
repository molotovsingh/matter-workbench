# Matter Workbench v1.0.0-beta.78

Date: 2026-06-28

Codename: **Nameplate Lantern**

This is a small vanity/clarity release. It makes the app show the release codename in the visible app chrome and in the “What’s new” note, rather than exposing only the technical release byte.

## Release Position

Release as:

```text
v1.0.0-beta.78
```

Tag target / deployed commit:

```text
53157e5 Show release codename in app chrome
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.77

User-facing changes:

- `/api/config` now exposes release `version` and `codename` alongside label, commit, date, and note;
- the title bar release badge now prefers the codename, falling back to label/version/commit when needed;
- the release badge tooltip still carries the technical release details;
- the “What’s new” login note now includes the codename and release version;
- the VM deploy command can stamp `MWB_RELEASE_VERSION` and `MWB_RELEASE_CODENAME` during activation.

## Not Promised

This release does not add historical release browsing inside the app, persistent per-user read/unread tracking, or an operator-managed release-notes editor.

The purpose is simple: the current beta should feel named and recognizable in the app, while the technical commit remains available for operators.

## Operator Notes

When deploying future named releases, pass both `--release-version` and `--release-codename` to `private-vm:rsync-deploy`. The app will show the codename, while the tooltip and `/api/config` keep the exact version/commit for support.
