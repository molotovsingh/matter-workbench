## Included Since beta.122

- Canonicalizes the neutral chronology as **Case Timeline**:
  - canonical artifacts are `10_Library/Case Timeline.md`, `.json`, and `.csv`;
  - canonical operation names are `/create_case_timeline`, `case-timeline`, and `/api/case-timeline`;
  - legacy `/create_listofdates`, `/api/create-listofdates`, and `10_Library/List of Dates.*` remain compatibility/fallback only.
- Adds the first MW-authored **MW List of Dates** Case Analysis workflow:
  - `GET /api/mw-list-of-dates/status?matter=...`;
  - `POST /api/mw-list-of-dates`;
  - native skill `/create_mw_listofdates` with staged job receipts;
  - current artifacts under `20_Workshop/Case Analysis/MW List of Dates.md` and `.json`;
  - previous current versions archived under `20_Workshop/Case Analysis/archive/` before overwrite.
- Adds Matter Overview / Case Analysis UI for MW List of Dates readiness, creation, refresh, and opening the current artifact.
- Blocks MW List of Dates on missing or stale Case Timeline, Matter Story, Source Index, or Procedural Posture Diagnosis.
- Keeps unconfirmed procedural diagnosis blocked by default, with an explicit proceed-unconfirmed reason only for provisional beta use.
- Validates MW List of Dates output against Case Timeline row IDs, source labels, chronology order, and diagnosis adverse-fact handling.
- Keeps the Markdown lawyer-readable and hides internal source handles there; raw row/source handles remain in JSON/receipts for auditability.
- Updates React/backend command contracts so `/create_listofdates` stays hidden legacy compatibility while the ordinary registry uses canonical commands.

## Behavior

The product distinction is now explicit:

```text
10_Library/Case Timeline.*
  Neutral source-backed factual chronology.

20_Workshop/Case Analysis/MW List of Dates.*
  MW-authored working analysis selected/framed for the current procedural diagnosis.
```

MW List of Dates is not part of automatic preparation in this release. It is a manual Case Analysis action after Case Timeline, Matter Story, and Filing and Procedural Posture Diagnosis are current.

## Not Promised

This release does not create a court-facing filing List of Dates, SLP chronology, writ chronology, or export profile. MW List of Dates remains MW-authored working analysis for lawyer review.

This release does not make MW List of Dates automatic preparation. It does not silently proceed on unconfirmed procedural diagnosis. It does not reopen raw source documents or run legal research inside MW List of Dates V1; the workflow transforms selected Case Timeline rows.

Ask remains matter-record-only. Statutes and public law remain Research-only.
