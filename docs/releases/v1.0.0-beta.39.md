# Matter Workbench v1.0.0-beta.39

Date: 2026-06-24

Codename: **Draft Finch**

This is a Beta 3 Skills page copy/readability release. It keeps beta.38's
actionable workflow table and fixes confusing draft skill titles shown in the
Skills in-progress area.

## Release Position

Release as:

```text
v1.0.0-beta.39
```

Tag target / deployed commit:

```text
1f59d6d Make draft skill titles user-facing
```

The tag points to the exact code installed on the DigitalOcean beta VM.

This release note is recorded in a later documentation commit on `main`; the
running product code remains the tagged deployed commit above.

Meaning:

- Beta 3 remains the accepted private-cloud beta line;
- the deployed product remains the React-only private beta with runtime DB
  storage;
- draft skill rows no longer expose planner phrasing such as `Create a reusable
  skill to produce...`;
- placeholder `unknown` skill ideas fall back to `Unfinished skill idea`;
- `Skills in Progress` copy is softened to workflow language;
- `Continue` becomes `Continue setup` and `Park` becomes `Save for later`.

## Included Since beta.38

Skills page readability:

- humanized saved skill idea titles from planner instructions into workflow
  names, for example:
  - `Simple list of parties in the matter`;
  - `Comparison chart of terms`;
  - `Explain in detail`;
  - `Draft a client update email from the latest matter record`;
  - `Synopsis`;
- changed in-progress section labels to `Workflows in progress`, `Draft custom
  workflows`, and `Draft workflow ideas`;
- changed draft actions to `Continue setup` and `Save for later`;
- added regression tests for the confusing screenshot titles.
