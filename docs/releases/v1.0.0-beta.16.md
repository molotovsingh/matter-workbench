# Matter Workbench v1.0.0-beta.16

Date: 2026-06-17

This is the Beta 3 diagnostic-closeout marker for the private-cloud beta line.

It advances the deployed Beta 3 runtime from the beta.15 System Health /
feedback / credit-shadow marker to a diagnostic-hardening checkpoint. The goal
of this marker is supportability, not new product scope.

## Release Position

Release as:

```text
v1.0.0-beta.16
```

Tag target:

```text
b58ba8c Add shared path error codes
```

Meaning:

- the deployed private beta remains the React-only product UI;
- runtime DB storage remains the accepted hosted-beta path;
- DigitalOcean deployment uses the repeatable `private-vm:rsync-deploy` flow;
- runtime and mothership services are expected to be active;
- diagnostic codes are now stable across the main hosted-beta failure surfaces;
- credit metering remains shadow/report-only, with no billing or enforcement;
- no public SaaS signup, self-service billing, or unsupervised legal reliance is
  implied.

## Included Since beta.15

Diagnostic hardening added stable operator-facing codes for:

- runtime DB query/storage, upload/allocation, and materialized-operation paths;
- multipart upload and browser-relative path validation;
- private beta feedback validation;
- cross-cutting HTTP JSON request parsing;
- workspace preview/raw-file reads;
- stale durable-job detection;
- local JSON-backed Skill Factory idea/sample stores;
- local JSON-backed configurable-skill stores and run ledgers;
- Matter Copilot validation and provider-configuration failures;
- Skill Factory sample-output validation and provider-configuration failures;
- rerun-advice validation failures;
- source-descriptor batch/all-failed diagnostics;
- shared matter/path containment validation.

The diagnostic contract is documented in
[`docs/contracts/diagnostic-surfaces.md`](../contracts/diagnostic-surfaces.md).

## Remaining Known Diagnostic Gaps

The remaining uncoded `makeHttpError` sites are concentrated in broader local
surfaces rather than the hosted runtime DB read/write paths:

- configurable-skill lifecycle/creation/provider paths;
- local filesystem matter-store selection/resolution paths;
- local filesystem upload-service orchestration paths.

Treat those as future hardening candidates. They are wider and more
user-visible than the low-risk diagnostic-code slices included in this marker.

## Not Promised

This release still does not promise public SaaS signup, self-service password
reset, unsupervised legal reliance, external object storage, hard credit
enforcement, or a multi-region production posture. It is a private-cloud beta
for trusted testers.
