## Included Since beta.108

- Standardized the Filing and Procedural Posture Diagnosis JSON sidecar with:
  - `simple_case_view`;
  - `legal_routes[]`;
  - `recommended_route`;
  - `next_best_actions`.
- Updated proposer/critic/finalizer instructions to require simple Indian legal English, all probable legal routes supported by the current record, reasons, statutory references, lawyer-confirmation items, and next best actions.
- Preserved backward-compatible fields (`court_forum`, `procedural_posture`, `possible_filings`, and `recommended_working_path`) so older artifacts still render.
- Reworked the markdown renderer into predictable prose-like sections:
  - Simple case view;
  - Current procedural position;
  - Legal routes available from current record;
  - Recommended route;
  - Next best actions;
  - Information the lawyer must confirm.
- Updated Matter Overview to show the new simple view, recommended route, and next actions, while falling back to older court/forum, posture, and working-path fields when a legacy sidecar is loaded.
- Added source-level and fixture tests for the schema, prompt language, markdown route sections, runtime DB posture generation fixture, and UI summary fallback boundary.

## Not Promised

This release does not make the posture diagnosis lawyer-approved or filing-ready. The diagnosis remains provisional and limited to probable routes supported by the current record.
