## Included Since beta.17

Operator-side beta feedback triage improvements:

- mothership development reports include bounded `severity` and feedback
  `status` metadata;
- markdown reports redact installation identifiers in prioritized evidence;
- report summaries include blocker/error/warning/info evidence counts;
- `mothership:report` supports view-only filters:
  - `--action-lane fix_now|investigate|product_decision|watch`;
  - `--severity blocker|error|warning|info`;
  - `--status new|reviewed|needs_evidence|fixed|parked|not_reproducible`;
  - `--limit <positive integer>`;
- unsupported report filter values fail closed;
- the mothership operator can mark feedback triage status with
  `feedback update-status` using the existing `mothership_feedback_events.status`
  column;
- markdown reports print each prioritized evidence item ID so operators can copy
  the correct feedback/signal ID when triaging.

The operator-only triage design is documented in
[`docs/future-design-decisions/feedback-triage-router-plan.md`](../future-design-decisions/feedback-triage-router-plan.md).
