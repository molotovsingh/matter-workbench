# Matter Workbench v1.0.0-beta.89

Date: 2026-06-29

Codename: **Boring Queries**

This is an operator-only mothership investigation release on top of beta.88. It adds a canned read-only query bundle so repeated tester complaints can be checked with one boring command instead of ad hoc SQL.

## Included Since beta.88

- Added `scripts/mothership-investigate.mjs`.
- Added package script:

```bash
npm run mothership:investigate -- --user shivangi --matter "National Insurance" --since-hours 72
```

- The command is read-only and uses `store.queryReport()` once.
- It reports matching feedback, open-feedback counts, nearby signals, nearby heartbeat journeys, latest heartbeat counters, and latest populated matching matter-health rows.
- Added regression tests for parsing, report bundling, read-only runner behavior, package exposure, and post-deploy empty-heartbeat handling.
- Documented the command in `deployment/private-vm/README.md`.
