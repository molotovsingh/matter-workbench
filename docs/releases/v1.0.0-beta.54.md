# Matter Workbench v1.0.0-beta.54

Date: 2026-06-25

This is a Beta 3 Skill Factory UX polish release. It adds a congratulatory toast
when a custom skill is successfully created.

## Release Position

Release as:

```text
v1.0.0-beta.54
```

Tag target / deployed commit:

```text
e59d939 Celebrate custom skill creation
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.53

Skill creation encouragement:

- adds a lightweight app toast surface;
- shows a dismissible success toast after a custom skill is created;
- uses encouraging copy: `🎉 Skill created` and `Nice work — ... is ready in
  Your Skills.`;
- auto-dismisses the toast after a short delay;
- preserves the existing created-state guidance, Skills refresh, and assistant
  shortcut refresh behavior from beta.53.

## Not Promised

This release does not change skill naming, approval, authoring, provider routing,
or runtime behavior. It only adds positive user feedback after successful skill
creation.

## Operator Notes

main workspace area. It should disappear automatically and can also be dismissed
manually. If rollback is needed, deploy `bb0d86a`.
