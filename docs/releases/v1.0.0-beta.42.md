# Matter Workbench v1.0.0-beta.42

Date: 2026-06-25

This is a Beta 3 Skills matter-selection continuation release. It keeps beta.41's
actionable `Choose matter` posture and carries the exact workflow the user chose
through matter selection, so selecting a matter resumes the intended Skills action
instead of dropping the user into a generic picker.

```text

```

Tag target / deployed commit:

```text

```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.41

Skills matter-selection continuation:

- stores the pending Skills action when a no-matter user clicks `Choose matter`;
- preserves the selected built-in workflow, custom skill, or draft workflow idea
  while routing to the matter finder;
- resumes the intended action after the user selects a matter;
- keeps the no-auto-pick posture: Matter Workbench still requires an explicit
  user-selected matter before matter-bound workflows run;
- clears the pending Skills action after use so later matter switches do not
  replay stale workflow intent;
- adds source-level regression coverage for the Skills chooser and App-level
  matter-selection resume path.

## Not Promised

This release does not auto-select matters and does not change workflow engines,
Research, Copilot behavior, or custom-skill persistence. It only preserves and
resumes the user-selected Skills action after explicit matter selection.

## Operator Notes

When no matter is active, Skills still says `Choose matter` and opens the matter
finder. After the user chooses a matter, Matter Workbench continues the workflow
that launched the chooser. If rollback is needed, deploy the recorded rollback
candidate `5fca803`.
