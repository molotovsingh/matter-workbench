# Matter Workbench v1.0.0-beta.77

Date: 2026-06-28

Codename: **Notice Bell**

This is a small tester-communication release. It adds a visible “What’s new” note after private beta login and a `/whats_new` command so testers can reopen the current beta guidance at any time.

## Release Position

Release as:

```text
v1.0.0-beta.77
```

Tag target / deployed commit:

```text
4a6831a Show beta what's new on login
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.76

Tester-facing changes:

- after sign-in and readiness checks, testers see a dismissible **What’s new** note;
- the note summarizes current beta testing points in plain language:
  - larger upload batches;
  - clearer long-upload and document-reading progress;
  - non-destructive archive/reopen;
  - non-destructive **Remove from active record**;
- testers can type `/whats_new`, `/whatsnew`, `whats new`, or `what’s new` in the command rail to reopen the note;
- `/whats_new` appears in command suggestions.

## Not Promised

This release does not add a full changelog system, per-user unread tracking, remote release-note editing, or Google Drive import.

The purpose is simple: every beta login now gives testers a clear reminder of what changed and what to try.

## Operator Notes

Use `/whats_new` during supervised sessions when a tester asks what changed. Keep the note short and plain-language; if it becomes long, move historical detail back to release notes instead of turning the login note into a changelog.
