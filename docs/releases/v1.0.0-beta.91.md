# Matter Workbench v1.0.0-beta.91

Date: 2026-06-29

Codename: **Focus Lens**

This is an operator-only follow-up to beta.90. It changes the canned mothership investigation semantics so reporter/user is focus context rather than the default evidence filter.

## Release Position

Release as:

```text
v1.0.0-beta.91
```

Tag target / deployed commit:

```text
8344c04 Treat mothership user as investigation focus
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.90

- `--user` is now a short alias for `--focus-user`.
- `--focus-user` highlights matching reporter feedback but does not exclude other evidence.
- Added `--reported-by` for the rare strict reporter-filter case.
- Investigation scope is now explicitly matter/text/preset/time-window driven.
- Report output includes focus-user feedback counts and marks focus-user feedback rows.
- Operator docs describe focus-user vs strict reporter filtering.
- Regression tests cover focus-user highlighting and strict reporter filtering.
