# Matter Workbench v1.0.0-beta.20

Date: 2026-06-17

This is the Beta 3 misfiled-feedback triage marker. It keeps the beta.19
audit loop and adds conservative deterministic routing for product/UX/positive
notes that trusted testers filed through the bug channel.

## Release Position

Release as:

```text
v1.0.0-beta.20
```

Tag target / deployed commit:

```text
20a46b5 Route misfiled beta feedback deterministically
```

Branch documentation commits after `20a46b5` record this release note and
current-release pointers only; they do not change the hosted product behavior
covered by the beta.20 tag.

Meaning:

- the deployed private beta remains the React-only product UI;
- runtime DB storage remains the accepted hosted-beta path;
- DigitalOcean deployment uses the repeatable `private-vm:rsync-deploy` flow;
- runtime and mothership services are expected to be active;
- the operator feedback-triage loop can review, filter, mark, audit, and now
  deterministically re-route obvious misfiled beta feedback without changing
  tester-facing intake;
- no provider calls are required for feedback triage;
- credit metering remains shadow/report-only, with no billing or enforcement;
- no public SaaS signup, self-service billing, or unsupervised legal reliance is
  implied.

## Included Since beta.19

Operator-side feedback-triage routing improvements:

- bug-channel product/workflow requests route to `feature_request` /
  `product_decision` when they do not include concrete malfunction language;
- onboarding/help-copy complaints filed as bugs route to `confusing_ux` /
  `product_decision`;
- positive notes and operator/test smokes filed as bugs route to
  `operator_note` / `watch`;
- concrete product-control failures, legal-quality concerns, preparation
  failures, auth issues, and unsupported-citation bugs remain on their existing
  deterministic paths;
- report/status audit metadata from beta.19 remains intact.

The operator-only triage design is documented in
[`docs/future-design-decisions/feedback-triage-router-plan.md`](../future-design-decisions/feedback-triage-router-plan.md).
