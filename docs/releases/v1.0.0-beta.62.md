# Matter Workbench v1.0.0-beta.62

Date: 2026-06-26

Codename: **Payload Sieve**

This is a Beta 3 runtime DB active-source read hardening release. It prevents
runtime DB workspace and payload reads from surfacing derived extraction/text
payloads when those payloads are linked to inactive source documents.

## Release Position

Release as:

```text
v1.0.0-beta.62
```

Tag target / deployed commit:

```text
43e1f33 Filter inactive source derived payload reads
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.61

Runtime DB inactive-source derived payload filters:

- workspace reads now join extraction/text payload custody back to source
  document identity where available;
- payload reads apply inactive source-document filters to linked extraction/text
  payloads, not just source originals / working copies;
- inactive statuses remain aligned with the active-source contract:
  `removed_from_active_record`, `quarantined`, `deleted_pending`, and `deleted`;
- tests lock the derived-payload joins and filters.

Safety posture:

- no source-removal write path is added;
- no lawyer-facing remove/delete UI is added;
- no physical purge behavior is added;
- this is read-side suppression only, preserving custody/history rows.
