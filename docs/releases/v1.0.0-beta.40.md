# Matter Workbench v1.0.0-beta.40

Date: 2026-06-24

Codename: **Workflow Bell**

This is a Beta 3 Skills page readability release. It keeps beta.39 draft-title
cleanup and simplifies the built-in workflow table so it reads like user tasks,
not internal registry metadata.

## Release Position

Release as:

```text
v1.0.0-beta.40
```

Tag target / deployed commit:

```text
13f4562 Simplify built-in workflow labels
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.39

Skills page built-in workflow cleanup:

- replaced registry/operator row titles with task names:
  - `Set up the matter`;
  - `Prepare the matter`;
  - `Read documents`;
  - `Create document index`;
  - `See assistant context`;
  - `Find in matter`;
  - `Create List of Dates`;
  - `Draft Matter Story`;
  - `Check readiness`;
- removed internal category sublabels such as `Ingest`, `Prepare`, `Review`,
  and `Analyze` from the row body;
- removed the noisy `Built-in` badge from each row;
- changed the table headers to simpler terms: `Workflow`, `Use it for`,
  `Action`, `Shortcut`;
- changed the section heading to `Choose a workflow`;
- made built-in action buttons visually quieter while keeping shortcuts visible.
