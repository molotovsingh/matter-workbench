# Matter Workbench v1.0.0-beta.6

Date: 2026-06-07

Codename: **Evidence Satchel**

This is the private beta ops-loop checkpoint.

It keeps the React-only local/private beta, accepted runtime DB mode, private VM
service pack, and `v1.0.0-beta.5` release closure command. The new slice adds a
repeatable bug evidence pack so private beta feedback can be handed back to
development with enough context to reproduce and triage the issue, without
sharing raw client files or secrets by default.

## Release Position

Release as:

```text
v1.0.0-beta.6
```

Meaning:

- the React shell remains the only product UI at `/`;
- runtime DB mode remains accepted for local/private beta operation when the
  explicit runtime flags and safe runtime role are used;
- private VM operation remains private-network only, not public SaaS;
- release-candidate judgment still uses `npm run private-beta:rc-closure-pack`;
- routine bug handoff now uses `npm run private-beta:bug-evidence-pack`.

## Included

- Everything from `v1.0.0-beta.5`.
- Private beta bug evidence pack.
- Operator documentation for bug handoff evidence.
- Updated checklist language separating:
  - routine health evidence;
  - one-bug handoff evidence;
  - recoverability evidence;
  - release-candidate closure evidence.

## Private Beta Bug Evidence

The bug evidence command:

```bash
npm run private-beta:bug-evidence-pack -- \
  --base-url http://127.0.0.1:4191 \
  --matter "Matter Name" \
  --note "Short bug description"
```

writes Markdown and JSON evidence under
`.local/private-beta-bug-evidence-packs/` by default.

On the private VM, run it after loading `runtime.env` and write output under
`$HOME/matter-workbench-backups/bug-evidence`.

The pack captures:

- operator note;
- target matter name;
- live service smoke;
- runtime DB posture;
- current deployment and rollback candidate from the ops pack;
- recent command-panel interactions;
- paths to evidence files that should be attached to a developer handoff.

The pack redacts common secret shapes and does not include raw matter document
bodies. Operators should still review the generated evidence before sharing it.

## Not Promised

This release does not promise:

- public hosted SaaS deployment;
- HTTPS/TLS termination;
- multi-user hosted auth/session middleware;
- cloud object storage;
- durable background workers that survive browser/process shutdown;
- unsupervised legal reliance;
- perfect OCR on bad scans;
- final court-ready drafting.

The exact claim is narrower: private beta operation now has a repeatable loop
for collecting bug evidence, checking service/ops posture, and handing issues
back to development without relying on loose screenshots and memory.

## Release Judgment

This checkpoint is about beta operations, not product expansion. A private beta
is only useful if reported issues can be captured cleanly, reproduced, and
triaged without asking the tester to remember terminal state or attach raw
client material. The bug evidence pack closes that gap.
