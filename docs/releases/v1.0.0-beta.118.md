# Matter Workbench v1.0.0-beta.118

Date: 2026-07-02

Codename: **Markdown Glass**

This is a supervised beta UX release that renders generic Markdown matter documents as readable documents instead of raw Markdown text.

The tag points to the exact app code installed on the DigitalOcean beta VM. The release documentation is recorded on `main` after the immutable tag target.

## Included Since beta.117

- Added one shared safe React Markdown viewer for generic matter `.md` previews.
- Installed the approved renderer stack: `react-markdown`, `remark-gfm`, and `rehype-sanitize`.
- Added a local Markdown URL guard that rejects dangerous schemes such as `javascript:`, `vbscript:`, `data:`, `file:`, and protocol-relative links.
- Skips raw HTML in Markdown and avoids `dangerouslySetInnerHTML`.
- Keeps the specialized Case Timeline/List of Dates preview unchanged.
- Lazy-loads the Markdown viewer so the main React bundle stays below the chunk warning threshold.
- Recorded the ambient activity and Markdown rendering future-design contracts.

## Behavior

When a user opens an ordinary saved Markdown document such as Filing and Procedural Posture Diagnosis, the file preview now renders headings, lists, tables, blockquotes, and inline code as a document. Users no longer need to understand raw Markdown syntax to read the saved artifact.

The Case Timeline/List of Dates preview still uses its existing legal-specific table renderer with source-label handling. JSON, CSV, extracted records, and other non-Markdown previews are unchanged.

## Not Promised

This release does not add direct document editing, syntax highlighting, Mermaid diagrams, raw HTML rendering, markdown-to-PDF export, or broad Copilot/Activity Markdown rendering. It only renders generic saved `.md` file previews while preserving specialized legal previews.

## Operator Notes

Use `v1.0.0-beta.118` for supervised testing. If a Markdown document looks wrong, first check whether it is a generic `.md` preview or the specialized Case Timeline preview; only generic `.md` files are newly rendered by this release.
