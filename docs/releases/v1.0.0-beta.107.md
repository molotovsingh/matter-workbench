## Included Since beta.106

- Matter Overview now passively polls durable backend jobs for the active matter instead of only tracking jobs started in the current browser session.
- Queued/running/retrying preparation jobs are projected into the Matter Preparation card as a running preparation state with the copy: **Preparation running on server…**
- Runtime preparation job kinds observed in the overview now include matter init, extraction, source labels, Case Timeline, Matter Story, and procedural posture diagnosis.
- **Run needed preparation** and the advanced full-rebuild controls are disabled while either a local preparation run or a relevant backend job is active, reducing duplicate queue attempts after refresh/reconnect/another tab.
- When the overview has observed an active backend preparation job and it later finishes, the app refreshes the active matter workspace and preparation plan with an expected-matter guard.
- Failed/cancelled backend preparation jobs show safe user-facing copy and keep raw backend/provider job text out of the Matter Overview surface.
- Added source guards in `test/react-preparation-job-observer.test.mjs` and updated the existing preparation UI guard test.
