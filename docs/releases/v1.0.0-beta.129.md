Codename: **Case Thread**

## Included Since beta.128

- Tunes MW List prompt instructions so Chapter 1 builds a progressive client narrative where supported:
  - transaction and allotment;
  - client payments/performance;
  - delay/handover issues;
  - registration/payment pressure;
  - respondent default allegations;
  - client rebuttal/procedural response.
- Asks the selector to avoid low-value background rows unless they affect relief, default, possession, registration, limitation, or dues.
- Keeps disciplined client-favouring advocacy while prohibiting final-finding words unless sourced as allegations.
- Shortens the Chapter 1 intro so it reads less like product copy.
- Improves display of inferred client side for matters like Roma Builder, showing `Complainants / flat purchasers — to be confirmed` when the saved diagnosis did not explicitly set client side but the matter/frame/rows support that apparent posture.
- Preserves beta.128 UI behavior: Markdown table date columns do not wrap.

## Behavior

The MW List remains:

```text
Chapter 1 — Working List of Dates
Chapter 2 — Basis, Assumptions, and Review Notes
```

The tuning is semantic, not structural. It is intended to make Chapter 1 feel less mechanical and more like the lawyer’s working chronology for the apparent client, while still treating respondent assertions as assertions and disputed matters as disputed.

## Not Promised

This release does not create a court-facing filing List of Dates, SLP chronology, writ chronology, or export profile. MW List of Dates remains MW-authored working analysis for lawyer review.

This release does not make MW List of Dates automatic preparation. It does not silently proceed on unconfirmed procedural diagnosis. It does not reopen raw source documents or run legal research inside MW List of Dates V1; the workflow transforms selected Case Timeline rows.

This release does not introduce a golden baseline fixture for the exact approved Roma output. That remains a possible follow-up if the team wants to lock a model-response exemplar for regression review.
