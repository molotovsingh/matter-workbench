# Matter Workbench v1.0.0-beta.45

Date: 2026-06-25

This is a Beta 3 internal architecture release. It continues the AI provider
service migration by routing Skill Interview Planner and Copilot Research answer
synthesis through the first-class provider boundary.

## Release Position

Release as:

```text
v1.0.0-beta.45
```

Tag target / deployed commit:

```text
2861d15 Route Copilot research answers through AI provider service
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.44

AI provider boundary continuation:

- migrated Skill Interview Planner provider calls through
  `services/ai-provider-service.mjs`;
- preserved the planner's deterministic fallback posture when disabled,
  unconfigured, or provider-failing;
- migrated Copilot Research answer synthesis through the same provider service;
- preserved Research answer schema, public-source ID validation, verification
  caveat, and provider configuration behavior;
- added task-specific OpenRouter header passthrough in the provider service so
  migrated providers keep their prior `x-title` routing metadata;
- kept `services.aiProvider` legacy slot unchanged to avoid moving List of Dates
  and runtime DB paths before their explicit migration stage.
