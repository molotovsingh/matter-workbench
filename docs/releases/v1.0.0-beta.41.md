# Matter Workbench v1.0.0-beta.41

Date: 2026-06-24

This is a Beta 3 Skills page interaction release. It keeps beta.40's simplified
workflow labels and replaces disabled no-matter skill buttons with an enabled
matter chooser.

## Release Position

Release as:

```text
v1.0.0-beta.41
```

Tag target / deployed commit:

```text
5fca803 Make skills matter selection actionable
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.40

Skills matter selection:

- replaced disabled `Pick matter first` buttons with enabled `Choose matter`
  actions;
- routed `Choose matter` to the existing matter finder;
- kept the no-auto-pick posture: users choose the matter before running a
  workflow;
- applied the same matter chooser behavior to built-in workflows, custom skill
  runs, and draft workflow idea setup;
- kept run/lifecycle race guards in place while removing the no-matter dead end.

## Not Promised

This release does not auto-select matters and does not change workflow engines,
Research, Copilot behavior, or custom-skill persistence. It only makes the
required matter-selection step actionable.
