# Matter Workbench v1.0.0-beta.84

Date: 2026-06-29

Codename: **Boundary Gauge**

This is an operations-hardening hotfix on top of beta.83. It adds an automated private-VM service-check probe for the user-facing AI error boundary, so future deployments fail closed if Assistant/provider failures leak backend wording.

## Release Position

Release as:

```text
v1.0.0-beta.84
```

Tag target / deployed commit:

```text
b2cb308 Probe AI error boundary in VM service check
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.83

- Private VM service check now conditionally probes `/api/skills/check-intent` when Assistant readiness is degraded.
- The probe treats `User not found`, provider/model/quota/key terminology, or other restricted AI language as a service-check failure.
- The service-check report now records:

```text
ai_error_boundary_probe
ai_error_boundary_status
ai_error_boundary_code
ai_error_boundary_language_leak
```

- This turns the beta.83 manual RCA verification into a recurring deployment gate.
