# Matter Workbench v1.0.0-beta.15

Date: 2026-06-16

This is the current Beta 3 private-cloud release marker.

It marks the deployed Beta 3 line after integrating three reviewed hardening
slices:

- read-only System Health;
- private-beta feedback triage;
- shadow credit metering.

## Release Position

Release as:

```text
v1.0.0-beta.15
```

Tag target:

```text
2a44c3e docs: align credit shadow json report command
```

Meaning:

- the deployed private beta runs from the React-only product UI;
- runtime DB storage remains the accepted deployed beta path;
- DigitalOcean deployment uses the repeatable `private-vm:rsync-deploy` flow;
- runtime and mothership services are expected to be active;
- database migration `019_credit_ledger.sql` is applied and recorded;
- System Health is available as an operator/local read-only surface;
- beta feedback is routed through the first server-side triage service;
- credit metering remains shadow/report-only, with no billing or enforcement.

## Included Since beta.12

- Read-only System Health API, CLI report, and Settings surface.
- Operator/local gating for System Health.
- Private-beta feedback triage service for bug, UX, feature-request, blocked
  workflow, legal-quality, and operator-note signals.
- Mothership report integration for feedback triage.
- Shadow credit policy, planner, report command, and credit ledger migration.
- Documentation cleanup for credit shadow semantics and system-health
  boundaries.

## Not Promised

This release still does not promise public SaaS signup, self-service password
reset, unsupervised legal reliance, external object storage, hard credit
enforcement, or a multi-region production posture. It is a private-cloud beta
for trusted testers.
