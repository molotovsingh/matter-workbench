# Matter Workbench v1.0.0-beta.85

Date: 2026-06-29

Codename: **OpenAI Relay**

This is a provider-configuration and routing hotfix on top of beta.84. It moves the live beta away from OpenRouter for the current supervised test path and adds code support for `/describe_sources` / Source Index labels to use OpenAI direct when selected.

## Release Position

Release as:

```text
v1.0.0-beta.85
```

Tag target / deployed commit:

```text
2abb153 Allow source labels to use OpenAI direct
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.84

- Live runtime provider configuration switched to OpenAI direct for:
  - Matter Assistant / Ask;
  - skill intent routing;
  - source labels / `/describe_sources`;
  - source-backed analysis paths that already supported OpenAI direct.
- The non-working VM OpenAI key was replaced with the working OpenAI key from the operator `.env` without printing key material.
- Non-working OpenAI key entries were scrubbed from VM runtime-env backup files.
- `SOURCE_DESCRIPTION_PROVIDER=openai-direct` is now supported by model policy and source descriptor provider resolution.
- Source labels keep OpenRouter support when explicitly selected, but are no longer hard-wired to OpenRouter.
- `.env.example` and model-routing docs now show OpenAI-direct source-label settings.
