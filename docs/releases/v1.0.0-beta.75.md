# Matter Workbench v1.0.0-beta.75

Date: 2026-06-28

This is a Beta 3 tester-feedback long-wait UX release. It makes matter creation/upload and document-reading preparation visibly active while the app is working, so long-running uploads or scanned-PDF extraction no longer look stuck.

Changes:

- New Matter now shows a visible “Working…” panel while checking duplicates and uploading;
- Add Files now shows the same visible wait status during duplicate checks and upload;
- upload wait copy tells testers to keep the page open and explains that large folders can take a few minutes;

- long-running preparation stages now emit elapsed-time heartbeat updates in the Matter Preparation progress card;
- preparation-run telemetry records the more useful running-stage message for document-reading stages.

## Not Promised

This release does not make OCR or extraction inherently faster, does not add background workers, does not add Google Drive import, and does not remove the need to keep the browser page open during current long-running preparation work.

The purpose of this release is trust and usability: testers now see that Matter Workbench is still working, what kind of work is happening, and why large/scanned records may take time.

## Operator Notes

If a tester says “it is taking too long,” first check whether the visible progress card is updating. Explain that large/scanned PDFs can take several minutes, and ask for the matter name and timestamp if the progress card stops updating or the stage fails.
