# Matter Workbench v1.0.0-beta.33

Date: 2026-06-24

This is a Beta 3 Copilot interaction-receipts release. It keeps beta.32 bounded
follow-up behavior and starts preserving compact Ask/Research receipts for
operator review and future product improvement.

## Release Position

Release as:

```text
v1.0.0-beta.33
```

Tag target / deployed commit:

```text
1a72422 Stamp Research answer policy metadata
```

The tag points to the exact code installed on the DigitalOcean beta VM.

Meaning:

- Beta 3 remains the accepted private-cloud beta line;
- the deployed product remains the React-only private beta with runtime DB
  storage;
- Ask and Research interactions now write compact local improvement receipts;
- receipts are not evidence, not legal artifacts, and not durable chat memory;
- receipts are operator-readable through an API;
- Research answer receipts now include model-policy metadata such as
  `copilot_web_research` and `openai/gpt-5.4`.

## Included Since beta.32

Copilot interaction receipts:

- added `services/copilot-interaction-receipt-service.mjs`;
- added `GET /api/copilot-interaction-receipts` for operator/local access;
- added compact receipt capture for Ask successes and failures;
- added compact receipt capture for Research successes and failures;
- receipt writes are best-effort and do not break user-facing routes;
- receipts redact secrets and avoid raw provider payloads or full matter context
  packets;
- documented the interaction-receipts policy in
  `docs/future-design-decisions/copilot-interaction-receipts.md`.

Research metadata hardening:

- stamped default Research answer-provider output with task/model/provider
  metadata from model policy;
- verified receipts include `copilot_web_research` and `openai/gpt-5.4` for
  Research answers.

## Not Promised

Receipts are not matter evidence and do not become `10_Library`, `20_Workshop`,
`30_Drafts`, or `40_Dispatch` artifacts. This release does not add a lawyer-facing
receipt browser, durable chat memory, receipt-to-training automation, or
mothership receipt analytics. It starts with a compact local/operator ledger.

## Operator Notes

Receipts can be read through:

```text
GET /api/copilot-interaction-receipts?matter=<name>&mode=ask|research&limit=100
```

Use receipts to inspect routing, answer status, source counts, warning patterns,
and provider/model metadata. If rollback is needed, deploy the recorded rollback
candidate `b55d5b2`.
