# Matter Workbench v1.0.0-beta.46

Date: 2026-06-25

This is a Beta 3 internal architecture release. It continues the AI provider
service migration by routing configurable skill authoring/runs and Source
Descriptors through the first-class provider boundary.

Release as:

```text

```


## Included Since beta.45

AI provider boundary continuation:

- migrated configurable skill authoring through `services/ai-provider-service.mjs`;
- migrated configurable skill validation/run providers through the same boundary;
- preserved custom skill creation, validation, lifecycle, runtime DB custody,
  and run-ledger behavior;
- migrated Source Descriptors / Document Index provider calls through the same
  boundary;
- preserved Source Descriptor request shape, approved fallback model behavior,
  retry semantics, and `ai_run` metadata merge behavior;
- preserved legacy direct provider factory exports as compatibility wrappers;
- kept List of Dates providers, OCR, provider-run ledger recording,
  AI settings, and startup checks for later stages.
