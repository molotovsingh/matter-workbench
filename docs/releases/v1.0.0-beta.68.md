Date: 2026-06-28

## Included Since beta.67

Archive confirmation backend fix:

- fixed the runtime DB matter archive/reopen lookup SQL used by `POST /api/matters/archive` and `POST /api/matters/reopen`;
- preserved the non-destructive archive contract: source files, generated artifacts, file IDs, and matter history are not deleted;
- added regression coverage so the mutation no longer orders by an unavailable SQL alias;
- manually verified archive and reopen on the live beta using a smoke matter, then re-archived that smoke matter to keep it out of the active list.
