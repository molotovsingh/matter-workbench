# Matter Workbench v1.0.0-beta.63

Date: 2026-06-26

Codename: **Artifact Sextant**

This is a Beta 3 artifact-currentness foundation release. It adds a durable
runtime DB schema and non-routed helpers for marking source-backed artifacts
current, stale, missing, blocked, or needing review before any source-removal UI
or mutation ships.

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.62

Artifact-currentness foundation:

- adds migration `022_matter_artifact_currentness`;
- creates tenant-scoped `matter_artifact_currentness` with RLS;
- supports artifact families `source_index`, `list_of_dates`, `matter_story`,
  and `custom_skill_output`;
- supports currentness states including `current`, `stale`, `missing`,
  `missing_upstream`, `failed`, `needs_review`, and `unknown`;
- preserves List of Dates dependency states such as
  `chronology_regeneration_needed`;
- adds local read-only currentness projection for Source Index, List of Dates,
  and Matter Story;
- adds source-removal currentness effect builders for future source-backed custom
  skill outputs;
- adds runtime DB upsert/list SQL helpers that can be embedded in future
  transaction-coupled source-removal mutations.

Safety posture:

- no source-removal write path is added;
- no lawyer-facing remove/delete UI is added;
- no physical purge behavior is added;
- no generated artifact is silently regenerated;
- currentness records store identifiers/metadata only, not source text or legal
  work product.
