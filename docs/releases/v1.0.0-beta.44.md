# Matter Workbench v1.0.0-beta.44

Date: 2026-06-25

This is a Beta 3 internal architecture release. It adds the first-class AI
provider service boundary and migrates the first provider-backed surfaces through
it without changing user-facing behavior.

## Release Position

Release as:

```text
v1.0.0-beta.44
```

Tag target / deployed commit:

```text
b217953 Route skill router through AI provider service
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.43

AI provider boundary foundation:

- added `services/ai-provider-service.mjs` with `invoke`, `invokeOcr`, `ping`,
  `resolveTask`, and `settingsSummary` as the first-class provider boundary;
- kept task policy in `shared/model-policy.mjs` and provider config in
  `shared/ai-provider-policy.mjs` authoritative;
- routed OpenAI Responses through the shared provider HTTP path while preserving
  compatibility exports;
- kept the legacy `services.aiProvider` slot unchanged so existing List of Dates
  and runtime DB paths do not silently move;
- migrated Matter Copilot answer generation to the provider service;
- migrated Skill Factory sample output generation to the provider service;
- migrated Skill Router / overlap classification to the provider service;
- preserved existing prompts, schemas, model policies, error codes, and
  fail-closed behavior for the migrated surfaces;
- left OCR and remaining provider surfaces for later stages.

## Not Promised

This release does not migrate OCR, List of Dates providers, source descriptors,
configurable-skill providers, web research providers, AI settings, startup
checks, or provider-run ledger recording. It is the first safe provider-boundary
foundation plus three migrated surfaces.
