## Included Since beta.100

- Collapsed the one-off `getFreshJson()` wrapper into the shared `getJson()` helper.
- Added an explicit `bypassCache` option for fresh GET requests.
- Centralized the runtime config cache-buster parameter and no-store fetch init constants.
- Preserved beta.100 behavior:
  - `/api/config` remains server-side `cache-control: no-store`;
  - React config fetches still use browser `cache: no-store`;
  - React config fetches still send `Cache-Control: no-store` and `Pragma: no-cache`;
  - React config fetches still include a throwaway `_mwbFresh` query token.
