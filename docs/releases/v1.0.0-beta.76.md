# Matter Workbench v1.0.0-beta.76

Date: 2026-06-28

Codename: **Closure Sextant**

This is an operator evidence-hardening release after the beta.75 tester-feedback closeout. It keeps the beta.75 user-facing long-wait and upload-limit behavior, and fixes two release-closure checks that were too brittle for the current private-beta VM.

## Included Since beta.75

Operational hardening:

- runtime DB browser acceptance now finds Settings in the Account footer as well as the main App navigation;
- shadow DB backup hashing now streams the backup file instead of reading the whole SQL dump into memory;
- the private VM recoverability pack now handles the current multi-GB database backup size.

Why this mattered:

- beta.75 app behavior was healthy, but the full RC closure pack initially failed on evidence tooling;
- the Settings check was stale after the UI intentionally moved Settings to the footer;
- the database backup proof failed when hashing a `2.66 GB` SQL dump because Node cannot read a file larger than `2 GiB` into one Buffer.
