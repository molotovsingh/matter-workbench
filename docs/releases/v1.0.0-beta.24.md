engineering/deployment side, with the deployed line verified, rollback known,
and any further hardening continuing as post-Beta-3 work.

```

```

Branch documentation commits after `457d7e4` record this release note and
current-release pointers only; they do not change the hosted product behavior
covered by the beta.24 tag.

Meaning:

- Beta 3 is closed, deployment verified, and rollback known;
- the deployed private beta remains the React-only product UI;
- runtime DB storage remains the accepted local/private beta custody path;
- foreground runtime workflows now use DB-native custody helpers and fail
  closed when required helper wiring is missing;
- the runtime DB full-matter materialized read/write bridge is removed from the
  active route/service surface;
- Skill Factory sample, creation, and run paths stay DB-native in runtime DB
  mode;
- tester-facing assistant copy remains neutral and provider-free;
- operator surfaces retain the technical evidence needed for support;
- no public SaaS signup, self-service billing, or unsupervised legal reliance is
  implied.
