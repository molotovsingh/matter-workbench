# Matter Workbench v1.0.0-beta.128

Date: 2026-07-09

Codename: **Date Rail**

This is a supervised beta UI patch for the MW List of Dates Markdown preview. It keeps date values in Markdown table first columns on one line, addressing the wrapped `DD/MM/YYYY` display seen in the chaptered MW List output.

## Release Position

Release as:

```text
v1.0.0-beta.128
```

Tag target / deployed commit:

```text
47560b1 Keep markdown date column on one line
```

The tag points to the exact Matter Workbench app code installed on the DigitalOcean beta VM. Release documentation is recorded on `main` after the immutable tag target.

## Included Since beta.127

- Adds a minimal Markdown table rendering rule:
  - first table column has `white-space: nowrap`;
  - first table column has a small minimum width.
- Leaves the rest of the MW List layout unchanged for this testing step.
- Keeps beta.127 content behavior unchanged:
  - Chapter 1 is the client-oriented working List of Dates;
  - Chapter 2 carries basis, assumptions, difficult facts, missing material, and review notes;
  - Date values remain `DD/MM/YYYY`;
  - internal `FILE-*` / `CT-*` handles remain hidden from default Markdown.

## Behavior

This release intentionally does not widen the document frame, shorten source labels, or redesign the table. It only prevents the date column from wrapping into stacked digits such as:

```text
08
/
09
/
20
10
```

Further table-width/source-label improvements can be tested separately if needed.
