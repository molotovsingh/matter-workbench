# Matter Workbench v1.0.0-beta.1

Date: 2026-05-17

This is the first V1 beta baseline for supervised legal-matter testing.

It is not a claim that legal output quality is finished. It is a checkpoint that
the app now has a justified, repeatable core workflow that future development
can build on without moving the foundation every day.

## Release Position

Release as:

```text
v1.0.0-beta.1
```

Meaning:

- the V1 product spine is present;
- the clean first-run beta path has passed real-matter acceptance;
- beta users can test the app under supervision;
- legal quality, prompt quality, UI clarity, and long-running-job ergonomics
  will keep improving incrementally.

## V1 Product Spine

The release baseline is:

```text
new/import matter
-> prepare matter
-> extract source records
-> create Source Labels / Document Index
-> create List of Dates
-> inspect outputs and matter attention
```

The important native-skill spine is:

```text
/matter-init -> /extract -> /describe_sources -> /create_listofdates
```

Product naming should continue moving toward:

- Source Labels / Document Index, rather than `/describe_sources`;
- Create List of Dates, rather than `/create_listofdates`;
- Matter Attention, rather than scattered logs.

## What Is Included

- Local matter workbench shell.
- Matter metadata and upload flow.
- Deterministic intake and extraction.
- Source Labels / Document Index generation.
- List of Dates generation with source-backed chronology artifacts.
- Label-refresh distinction from chronology regeneration.
- Matter Attention developer diagnostics.
- Command rail and native skill entry points.
- Custom-skill governance and sample-review path, but not as the V1 legal spine.
- Provider policy prompts for model-risk control.
- Fail-closed provider behavior with no silent fallback.

## What Is Not A Release Promise

This release does not promise:

- final court-ready legal drafting;
- unsupervised lawyer reliance;
- a polished Co-pilot mode;
- system-wide health monitoring;
- perfect source labels;
- perfect legal relevance prose;
- short runtime on very large matters;
- zero warnings in Matter Attention.

Warnings are expected in beta. The key release claim is that warnings are now
visible and the main runtime path is no longer silently broken.

## Known Follow-Up Themes

1. Long-running native skills need clearer progress and background-job
   semantics.
2. Source label quality will continue to improve through model/prompt work and
   possibly a second-pass polishing step.
3. Legal output review should focus on concrete missing events, overstated
   relevance, bad labels, weak citations, and source omissions.
4. Co-pilot mode should remain policy-defined but not allowed to blur ownership
   of lawyer-edited drafts.
5. System Health should remain separate from Matter Attention.

## Release Judgment

This is the right point to tag V1 beta.

The product has crossed from prototype behavior into a testable legal workbench
foundation. More quality work is necessary, but delaying a release checkpoint
would make future development harder to compare against a stable baseline.
