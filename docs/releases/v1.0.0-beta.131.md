# v1.0.0-beta.131 — Mothership Signal Lifecycle

Date: 2026-07-10

## Summary

- Added Mothership signal lifecycle status tracking: `active`, `resolved`, `superseded`, and `suppressed`.
- Default Mothership reports now hide non-active signals while preserving audit visibility with include-resolved views.
- Added operator/API support for updating signal status.
- Supersedes old job-status failure signals when a later same-matter/same-kind job succeeds, so stale failed jobs stop looking like live incidents.
