# Matter Workbench v1.0.0-beta.92

Date: 2026-06-29

Codename: **Signal Ladder**

This is an operator-only follow-up to beta.91. It turns mothership investigation into a two-stage read-only workflow: first collect candidate signals/matters, then focus on a selected signal, feedback item, or known matter.

## Release Position

Release as:

```text
v1.0.0-beta.92
```

Tag target / deployed commit:

```text
a253f29 Add two-stage mothership investigation workflow
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.91

- Added `npm run mothership:signals` as stage-one candidate collection.
- Added `npm run mothership:focus` as stage-two focused investigation.
- `mothership:investigate` remains the shared implementation behind both aliases.
- Added `--mode collect|focus`, `--signal-id`, and `--feedback-id` parameters.
- Reports now include candidate matters, candidate signals, stage-two seed metadata, and evidence gaps.
- Candidate matters aggregate feedback, open feedback, focus-user feedback, error signals, latest health, and short reasons.
- Operator docs now describe the two-stage workflow for unknown-case complaints.
- Regression tests cover stage-one candidates and stage-two signal focusing.
