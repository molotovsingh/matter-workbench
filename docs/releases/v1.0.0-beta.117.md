## Included Since beta.116

- Collapsed the duplicate visible `Case Analysis / Case Analysis` grouping in the Matter Files tree while preserving the underlying artifact path.
- Removed the raw saved-artifact path from the procedural posture summary copy and replaced it with lawyer-facing document wording.
- Closed the posture confirmation/correction/not-sure panel after a response is recorded.
- Kept a compact recorded-response message so the user can see that the decision was saved without leaving the form open.

## Behavior

The Matter Files sidebar now presents the `20_Workshop/Case Analysis/...` diagnosis artifacts directly under the visible **Case Analysis** lane instead of rendering a second nested **Case Analysis** folder. The real storage path is unchanged for compatibility and audit stability.

After the user clicks **Confirm working posture**, **Disagree / correct**, or **Not sure yet**, the confirmation panel no longer remains open as if more action is required. The panel is replaced by a short saved-response message.
