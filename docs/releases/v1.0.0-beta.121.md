# Matter Workbench v1.0.0-beta.121

Date: 2026-07-07

Codename: **Statute Lantern**

This is a supervised beta Research release that adds statutes-backed Research through a loopback Legal Source Sidecar.

## Release Position

Release as:

```text
v1.0.0-beta.121
```

Tag target / deployed commit:

```text
2354706 Add statutes-backed research provider
```

The tag points to the exact Matter Workbench app code installed on the DigitalOcean beta VM. The release documentation is recorded on `main` after the immutable tag target.

## Included Since beta.120

- Adds a Workbench Research provider mode:

  ```env
  COPILOT_WEB_RESEARCH_PROVIDER=legal_source_sidecar
  COPILOT_LEGAL_SOURCE_SERVICE_URL=http://127.0.0.1:8790
  ```

- Adds `services/legal-source-sidecar-provider.mjs`, a thin Workbench adapter for the loopback Legal Source Sidecar.
- Allows Research source validation for both `WEB-*` and `STATUTE-*` source IDs.
- Keeps the allow-list rule: model-cited public source IDs survive only if the retrieval provider actually supplied them.
- Threads safe sidecar/provider warnings into final Research answers with secret redaction.
- Caps sidecar snippets before answer-model input.
- Adds statute-aware Research prompt rules for `STATUTE-*` / `official_statute` sources.
- Renders Research sources separately as `Statute sources` and `Public web sources`.
- Adds implementation/runbook docs for the Legal Source Sidecar and statutes-powered Research.
- Builds the first standalone Legal Source Sidecar service at:

  ```text
  /Users/aksingh/legal-source-service
  ```

## Behavior

Research can now use exact statutory source snippets returned by the Legal Source Sidecar. Statutory sources appear as `STATUTE-0001`, `STATUTE-0002`, etc. Web/public sources continue to appear as `WEB-0001`, `WEB-0002`, etc.

Ask remains matter-record-only. Statutes are available through explicit Research mode, not ordinary Ask.

The beta VM is configured for statutes-only sidecar mode:

```text
COPILOT_WEB_RESEARCH_ENABLED=1
COPILOT_WEB_RESEARCH_PROVIDER=legal_source_sidecar
COPILOT_LEGAL_SOURCE_SERVICE_URL=http://127.0.0.1:8790
LEGAL_SOURCE_WEB_ENABLED=0
```

The sidecar calls the local statutes service and does not send Research queries to Exa/web search in the current live configuration.

## Not Promised

This release does not make statutes Research lawyer-verified or filing-ready. It does not claim the corpus is complete or current beyond the reported statutes health/corpus fingerprint. It does not enable sidecar web/Exa mode on the beta VM. It does not add a direct statute browser, direct statute command, statutory cross-reference UI, or durable research memo artifact.

Research remains chat-only by default. The answer caveat remains required:

```text
_Verify authorities before relying or filing._
```

## Operator Notes

Use `v1.0.0-beta.121` for supervised testing of statutes-backed Research.

If Research says it is unavailable, check:

```bash
systemctl --user is-active mwb-statutes.service
systemctl --user is-active mwb-legal-source.service
curl -s http://127.0.0.1:8788/health | jq
curl -s http://127.0.0.1:8790/health | jq
```

If the statutes health counts or fingerprint are not the intended corpus, rebuild the statutes DB under the sidecar directory and restart both sidecar services.
