# Matter Workbench v1.0.0-beta.72

Date: 2026-06-28

This is a Beta 3 tester-feedback fix release. It closes the current add-files / invalid matter name report by allowing runtime DB matters to resolve from lawyer captions containing slash characters such as `M/s`, while React keeps the API-safe folder name for backend mutations.

## Release Position

Release as:

```text
v1.0.0-beta.72
```

Tag target / deployed commit:

```text

```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.71

Tester feedback addressed:

- `feedback_6e5a8c83-6eac-4628-8e14-e6452b148ba0` — “Files not adding / Reflecting Invalid Matter Name”;
- `feedback_bcaae521-a5a4-4cad-8e22-30711c5fd98f` — “Not able to add files”.

Fixes:

- runtime DB matter lookup now tries both the verbatim lawyer caption and the derived safe storage name;
- captions with slash characters such as `M/s` can resolve to storage names such as `M - s`;
- React active-matter state now keeps the API-safe folder name as the mutation identifier;
- display title/status copy can still use the legal caption from matter metadata;
- Add Files shows the legal caption while submitting the safe matter identifier;
- archive/reopen lookup also accepts lawyer captions with slash characters.
