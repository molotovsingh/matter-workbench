## Included Since beta.107

- Extracted backend preparation job polling/projection from `react-ui/src/views/MatterOverview.tsx` into `react-ui/src/hooks/useBackendPreparationJobs.ts`.
- Kept Matter Overview as a consumer of the preparation observer instead of the owner of polling, job filtering, progress projection, and completion-refresh mechanics.
- Narrowed the UI-facing failure contract from a raw failed `JobStatus` object to a boolean `hasFailedJob`, so the Overview never receives raw failed-job detail fields it does not render.
- Preserved beta.107 behavior:
  - active backend preparation jobs still show **Preparation running on server…**;
  - **Run needed preparation** and force rebuild remain disabled while relevant jobs are active;
  - observed server-job completion still refreshes the active matter workspace and preparation plan;
  - failed/cancelled jobs still show safe user-facing copy without raw backend/provider leakage.
- Updated the observer source guards to assert the dedicated hook boundary and the narrowed safe-failure contract.
