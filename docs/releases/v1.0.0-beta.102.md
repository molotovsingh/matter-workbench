## Included Since beta.101

- Matter Overview now reads the full `/api/prepare-matter` plan instead of the older `/api/matter-status` summary.
- The **Prepared** badge now requires all required preparation stages to be current, including Matter Story and Filing and Procedural Posture Diagnosis.
- A matter with Case Timeline + Matter Story but missing procedural posture diagnosis now shows **Needs review** and the next step `/procedural_posture_diagnosis`.
- The default overview action is now **Run needed preparation**, using `mode: 'needed'` instead of forcing a full rebuild.
- Advanced **Force full rebuild** remains available, but requires a user reason and typing `REBUILD` before it can run `mode: 'full'`.
- Procedural posture missing/blocked copy now distinguishes unblocked missing diagnosis from upstream blockers.
- Copilot and timeout recovery copy now points users to **Run needed preparation**.
- The migration runner regression list now includes `024_first_class_upload_sessions`.

## Not Promised

This release does not auto-queue all post-upload preparation stages, make React observe backend preparation jobs, add chunked uploads, or generate missing procedural posture diagnoses for existing matters by itself. It fixes the overview readiness/read path and makes reruns safer.
