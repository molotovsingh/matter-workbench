# Matter Workbench v1.0.0-beta.32

Date: 2026-06-24

Codename: **Follow-up Fence**

This is a Beta 3 Copilot follow-up release. It keeps beta.31 Research
observability and adds bounded conversation context for ordinary Ask follow-ups,
while preserving the core rule that conversation state is not evidence.

## Release Position

Release as:

```text
v1.0.0-beta.32
```

Tag target / deployed commit:

```text
f2e4d0e Add bounded Copilot follow-up context
```

The tag points to the exact code installed on the DigitalOcean beta VM.

Meaning:

- Beta 3 remains the accepted private-cloud beta line;
- the deployed product remains the React-only private beta with runtime DB
  storage;
- Ask follow-ups may include a bounded recent conversation window;
- prior turns are used only to resolve references such as "that" or "after
  that";
- prior assistant answers are not evidence and cannot be cited;
- every factual answer still has to be grounded in the current matter context;
- no durable conversation memory or matter artifact is introduced.

## Included Since beta.31

Copilot follow-up context:

- added a bounded `conversation` request field to `/api/matter-copilot/answer`;
- React sends the last visible in-session thread turns for Ask requests;
- backend clamps conversation context to the last 4-6 turns / bounded character
  budget;
- provider prompt now says prior turns are only for reference resolution and are
  not evidence;
- response context records `conversation_turns` for debugging;
- tests prove the provider receives bounded conversation context and still
  validates sources against the matter packet.

## Not Promised

This release does not add durable Copilot memory, persisted chat history, or
conversation-as-evidence. It does not send prior turns to durable skill runs,
source labels, List of Dates, or artifact-writing workflows. Follow-up context
is bounded and used only for ordinary Ask reference resolution.

## Operator Notes

If a follow-up answer seems unsupported, check whether the returned answer has
validated matter citations. Prior assistant text should never be treated as a
source. If rollback is needed, deploy the recorded rollback candidate `6ca60e8`.
