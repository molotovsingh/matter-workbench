Date: 2026-07-09

Codename: **Timeline Nameplate**

This is a supervised beta UX patch release that completes the visible Case Timeline label cleanup for matters that still carry legacy `10_Library/List of Dates.*` storage objects.

## Included Since beta.123

- Hides legacy neutral-chronology storage names in the React workspace tree:
  - legacy `10_Library/List of Dates.md` displays as `Case Timeline.md`;
  - legacy `10_Library/List of Dates.json` displays as `Case Timeline.json`;
  - legacy `10_Library/List of Dates.csv` displays as `Case Timeline.csv`.
- Hides the same legacy name in file-preview breadcrumbs/title copy.
- Recognizes canonical `10_Library/Case Timeline.*` paths directly in artifact presentation labels.
- Preserves all compatibility behavior:
  - no existing DB/file objects are renamed by this patch;
  - legacy readers and fallbacks still work;
  - new Case Timeline writes remain canonical;
  - MW List of Dates remains the separate Case Analysis workflow under `20_Workshop/Case Analysis/`.

## Behavior

Existing beta matters may still physically contain legacy storage objects from earlier releases:

```text
10_Library/List of Dates.md
10_Library/List of Dates.json
10_Library/List of Dates.csv
```

In the lawyer/operator workspace UI, those legacy neutral-chronology files now present as:

```text

10_Library/Case Timeline.json
10_Library/Case Timeline.csv
```

This is a display-layer cleanup only. It removes visible old naming debt without migrating historical custody keys during the private beta patch window.

## Not Promised

This release does not create a court-facing filing List of Dates, SLP chronology, writ chronology, or export profile. MW List of Dates remains MW-authored working analysis for lawyer review.

This release does not migrate or rename historical runtime DB storage object keys. It only prevents legacy neutral-chronology names from leaking into the visible workspace UI.

This release does not change Case Timeline generation, MW List of Dates generation, legal research, statutes sidecars, data custody semantics, upload behavior, auth, or model routing.

Ask remains matter-record-only. Statutes and public law remain Research-only.
