# Matter Workbench v1.0.0-beta.3

Date: 2026-05-25

This is the owner-accepted React local beta checkpoint.

It is the first tag after the React-only cutover, database-prep migrations, and
rendered browser QA polish pass. The release target is still supervised local
beta, not unsupervised production use.

## Product Spine

The release baseline remains:

```text
new/import matter
-> prepare matter
-> extract source records
-> create Source Labels / Document Index
-> create List of Dates
-> inspect outputs and matter attention
```

The important native-skill spine remains:

```text
/matter-init -> /extract -> /describe_sources -> /create_listofdates
```

React-only product surfaces covered by the beta checkpoint:

- Home and matter selection;
- matter overview, file tree, preparation card, and advisory;
- Copilot greeting and matter-bounded answer path;
- Skills page, custom-skill creation/modification/run/lifecycle controls;
- Activity receipts and output opening;
- Settings provider status and model route visibility;
- narrow viewport smoke for the local beta shell.

## Included

- React/Vite production shell at `/` and `/react/`.
- React-only serving, with no plain-JS product fallback.
- Matter creation/import and add-files flow.
- Mandatory matter preparation path.
- OCR-first PDF extraction policy with current configured providers.
- Source Labels / Document Index.
- List of Dates.
- Preparation Advisory / Matter Attention.
- Copilot as transient, bounded matter Q&A.
- Custom skill creation, modification, run receipts, and lifecycle controls.
- Database migration files and database doctor as preparation for future hosted
  control-plane work.

## Not Promised

This release does not promise:

- unsupervised legal reliance;
- final court-ready drafting;
- hosted multi-user deployment;
- database-backed runtime state;
- perfect OCR on bad scans;
- perfect source labels or legal relevance prose;
- background jobs that survive browser/process shutdown;
- low latency on every large matter;
- zero preparation warnings.

Warnings are expected in beta. The release claim is that the app is coherent
enough for supervised local beta use and that warnings/errors are visible
enough to guide review and repair.
