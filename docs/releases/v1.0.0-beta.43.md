# Matter Workbench v1.0.0-beta.43

Date: 2026-06-25

This is a Beta 3 Skill Factory hotfix release. It fixes the saved-skill sample
flow where `Generate sample` could return `Matter not found` even though the UI
showed an active matter.

## Release Position

Release as:

```text
v1.0.0-beta.43
```

Tag target / deployed commit:

```text
cedf353 Use selected matter for skill samples
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.42

Skill sample matter selection hotfix:

- sends the selected active matter with Skill Factory sample-generation requests;
- uses the latest active matter ref at sample-click time, avoiding stale assistant
  session closures;
- makes the filesystem route honor an explicit sample `matterName` instead of
  relying only on process active matter;
- keeps runtime DB sample generation DB-native while preferring the explicit
  selected matter over stale saved-idea matter metadata;
- adds regression coverage for the exact failure class: stale saved idea matter
  metadata plus a valid selected current matter.
