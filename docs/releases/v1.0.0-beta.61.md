# Matter Workbench v1.0.0-beta.61

Date: 2026-06-26

This is a Beta 3 active-source currentness release. It makes local rerun advice
respect suppressed sources so stale Source Index and List of Dates artifacts are
not treated as current after the active source set changes.


The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.60

Active-source currentness advice:

- seeds local rerun advice from `.matter-workbench/source-tombstones.json` and
  inactive File Register rows;
- excludes suppressed extraction records from Source Index and List of Dates
  rerun/currentness checks;
- marks Source Index stale when it still contains a descriptor for a source that
  is no longer active;
- marks List of Dates stale with `chronology_regeneration_needed` when its
  source snapshot still references a source that is no longer active;
- avoids treating stale Source Index entries for inactive sources as new active
  chronology inputs.

Source-removal planning foundation:

- adds a draft source-custody removal write contract documenting the future
  transaction/idempotency/event requirements;
- adds a pure read-only source-removal impact preview helper;
- keeps that helper unrouted and invisible: no endpoint, no UI, and no mutation.

Safety posture:

- no source-removal write path is added;
- no lawyer-facing remove/delete UI is added;
- no physical purge behavior is added;
- `FILE-NNNN` ids remain stable and are not renumbered;
- source-removal events remain future work; unsafe `source_file.deleted` /
  `source_document.deleted` vocabulary remains blocked.

## Not Promised

This release does not add file removal, source-removal writes, restore,
quarantine workflows, physical deletion, outbox publishing, or Kafka/broker
integration. The impact-preview helper is intentionally not routed.

Conversation memory and Copilot receipts remain non-evidence.

## Operator Notes

No new user action is required. Existing matters without a suppression manifest
or inactive File Register rows behave as before. If a matter contains suppressed
sources, rerun advice now warns that Source Index/List of Dates outputs are stale
instead of implying they are current. If rollback is needed, deploy `f71fe71`.
