# Matter Workbench v1.0.0-beta.49

Date: 2026-06-25

This is a Beta 3 Skill Factory UX hardening release. It removes internal context
limit/debug language from Skill Factory sample output and saved sample rendering.

Release as:

```text
v1.0.0-beta.49
```

Tag target / deployed commit:

```text

```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.48

Skill Factory sample warning cleanup:

- hides internal context-limit warnings such as `maxBlocks`,
  `maxCharsPerBlock`, omitted evidence blocks, and truncated evidence blocks
  from the Skill Factory sample card;
- filters the same internal warnings from newly generated sample responses;
- prevents internal evidence-limit counts from being sent to the sample provider
  in the sample matter-context payload;
- keeps useful lawyer-facing reliability warnings, such as OCR/source review
  concerns;
- adds backend and React regression tests for this failure mode.

## Not Promised

This release does not change context retrieval, evidence bounds, model policy,
or skill creation behavior. It only prevents internal context-bound diagnostic
language from leaking into Skill Factory sample UX.

## Operator Notes

If a tester asks about omitted evidence blocks, explain that sample generation
uses a bounded preview of the matter record and is not a full analysis. The UI
should no longer show raw `maxBlocks` or `maxCharsPerBlock` language. If the
sample UI regresses, rollback to `aac20aa`.
