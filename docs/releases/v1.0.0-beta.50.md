# Matter Workbench v1.0.0-beta.50

Date: 2026-06-25

Codename: **Account Hearth**

This is a Beta 3 UX release. It moves account/session controls out of the
workspace title bar and into a pinned sidebar account footer.

## Release Position

Release as:

```text
v1.0.0-beta.50
```

Tag target / deployed commit:

```text

```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.49

Sidebar/account UX:

- moved `Sign out` from the editor title bar to the sidebar footer;
- pinned `Settings` and `Sign out` together as account/session controls;
- kept the title bar focused on active matter, release badge, storage mode, and theme;
- removed the old titlebar logout styling;
- updated layout tests so the sidebar owns sign-out placement.
