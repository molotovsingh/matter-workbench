# Matter Workbench v1.0.0-beta.99

Date: 2026-06-30

Codename: **Fresh Badge**

This is a tiny operator-facing freshness release for the runtime config/release badge.

## Release Position

Release as:

```text
v1.0.0-beta.99
```

Tag target / deployed commit:

```text
389c8ed Prevent config API caching
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Why This Exists

A tester/operator saw an older codename in the UI while another tester saw the current codename. Live server state was correct, but `/api/config` did not explicitly send a cache-control header. Because the title-bar release badge is populated from `/api/config`, this release makes that response uncacheable.

## Included Since beta.98

- `GET /api/config` now sends:

```text
cache-control: no-store
```

- Added test coverage that the release metadata config response is explicitly no-store.
