# Matter Workbench v1.0.0-beta.70

Date: 2026-06-28

Codename: **Reason Seal**

This is a Beta 3 archive lifecycle metadata release. It adds an optional archive reason and archived-by metadata while keeping archive/reopen non-destructive.

## Included Since beta.69

Archive reason and lifecycle metadata:

- Archive confirmation now includes an optional `Reason for archive` field;
- archive reasons are capped at 500 characters;
- local matters persist the reason and actor metadata in `.matter-workbench/matter-lifecycle.json`;
- runtime DB matters persist archive reason, archived-by, reopen timestamp, and reopened-by metadata through migration `023_matter_archive_metadata`;
- `All matters → Archived` shows archived date, reason, and archived-by metadata when available;
- archive/reopen remains non-destructive: source files, generated artifacts, file IDs, payload bytes, and history are not deleted.
