## Included Since beta.109

- Extracted posture diagnosis schema, legal-route schema, normalizers, recommended-route normalization, sourced-text normalization, and markdown rendering into `services/procedural-posture-diagnosis-contract.mjs`.
- Kept `services/procedural-posture-diagnosis-service.mjs` focused on orchestration, readiness/status, provider loop execution, sidecar assembly, and lawyer confirmation/Q&A recording.
- Re-exported the public schema/renderer helpers from the service module to preserve existing imports.
- Extracted the Matter Overview posture summary panel into `react-ui/src/components/matters/PostureSummary.tsx`.
- Split React posture route/recommendation shapes into named TypeScript interfaces.
- Aligned `prototypes/posture-diagnosis-loop.mjs` with the same prompt, schema, critique schema, and markdown renderer used by the product path, removing stale duplicate schema/rendering code.
- Added source-guard tests so the output contract stays separated from orchestration and the Matter Overview continues to consume the extracted summary component.

## Behavior

This is intended as a behavior-preserving refactor of beta.109. User-facing posture diagnosis copy, legal-route sections, JSON field names, markdown section names, Matter Overview summary copy, and legacy sidecar fallbacks are unchanged.
