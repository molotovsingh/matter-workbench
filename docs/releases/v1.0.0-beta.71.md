# Matter Workbench v1.0.0-beta.71

Date: 2026-06-28

Codename: **Sidebar Bellows**

This is a Beta 3 archive confirmation layout polish release. It gives the left sidebar more room while Archive confirmation is open so the optional reason field and `Confirm archive` control are comfortable to read and use.


The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.70

Archive confirmation layout polish:

- the app shell now widens the left sidebar while the Archive confirmation panel is open;
- the wider panel gives the optional archive reason field, `Cancel`, and `Confirm archive` more usable space;
- the sidebar returns to normal width after cancel/confirm;
- compact/tablet/phone breakpoints keep the existing icon-rail behavior;
- no archive semantics changed: archive/reopen remains non-destructive.
