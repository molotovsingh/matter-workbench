# Matter Workbench v1.0.0-beta.29

Date: 2026-06-24

Codename: **Research Raven**

This is the Beta 3 Copilot Research mode release. It keeps the beta.28 upload
batch-cap hardening and adds an explicit Research path for firm lawyers who need
current public legal sources alongside the active matter record.

## Release Position

Release as:

```text
v1.0.0-beta.29
```

Tag target / deployed commit:

```text
8766df4 Update command panel copy tests
```

The tag points to the exact code installed on the DigitalOcean beta VM.

Meaning:

- Beta 3 remains the accepted private-cloud beta line;
- the deployed product remains the React-only private beta with runtime DB
  storage;
- the command rail now has explicit `Skill | Ask | Research` modes;
- `Ask` remains matter-record-only and source-backed;
- `Research` uses public web/legal sources plus matter context when enabled;
- Research uses Exa for public source search and OpenRouter / `openai/gpt-5.4`
  for answer synthesis;
- public sources are normalized to stable `WEB-000N` IDs and returned model
  citations are validated against those IDs;
- Research answers remain chat-only and do not write matter artifacts.

## Not Promised

Research mode is not a court-ready legal opinion, precedent database, or full
legal research platform. It does not guarantee exhaustive current law coverage.
It uses public web results and must be verified by a lawyer before relying or
filing.

Research answers do not write `10_Library`, `20_Workshop`, `30_Drafts`, or
`40_Dispatch` artifacts. Persistent Copilot memory and durable conversation
threads remain out of scope for this release.

## Operator Notes

If Research fails:

1. check `/api/config` for `copilotWebResearchEnabled`;
2. check the VM runtime env for `COPILOT_WEB_RESEARCH_ENABLED=1` and
   `EXA_API_KEY` presence;
3. distinguish Exa search failure from OpenRouter answer synthesis failure;
4. confirm ordinary `Ask` still works as the matter-record-only fallback;
5. if rollback is needed, deploy the recorded rollback candidate `9cf1b7b`.
