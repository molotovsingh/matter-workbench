# Matter Workbench v1.0.0-beta.22

Date: 2026-06-18

This is the Beta 3 operator feedback triage context marker. It keeps the
beta.21 successful-slow routing behavior and adds a bounded, redacted
`whatHappened` packet to each mothership operator report item so “what happened?”
is boring: current matter state, nearby signals/jobs, and a clear next action are
co-located in the report row.

## Release Position

Release as:

```text
v1.0.0-beta.22
```

Tag target / deployed commit:

```text
6cd8a9d Add boring feedback triage context
```

Branch documentation commits after `6cd8a9d` record this release note and
current-release pointers only; they do not change the hosted product behavior
covered by the beta.22 tag.

Meaning:

- the deployed private beta remains the React-only product UI;
- runtime DB storage remains the accepted hosted-beta path;
- DigitalOcean deployment uses the repeatable `private-vm:rsync-deploy` flow;
- runtime and mothership services are expected to be active;
- operator feedback reports now include bounded `whatHappened` context for every
  item;
- tester-facing feedback intake is unchanged;
- no automated AI feedback triage is introduced;
- credit metering remains shadow/report-only, with no billing or enforcement;
- no public SaaS signup, self-service billing, or unsupervised legal reliance is
  implied.

## Included Since beta.21

Operator-side feedback report improvement:

- heartbeat journey rows are correlated to same-installation, same-matter report
  items inside the existing two-hour evidence window;
- correlated heartbeat job state is exposed as bounded `relatedJobs` evidence;
- every report item gets a `whatHappened` packet with:
  - `currentMatterState` when heartbeat matter health is available;
  - up to three nearby signal summaries;
  - up to three nearby job summaries;
  - triage missing-evidence hints;
  - a redacted next action;
  - a compact one-line summary;
- markdown reports render the same boring context without exposing secrets or
  source text;
- existing routing/status behavior remains deterministic and operator-only.
