# Matter Workbench v1.0.0-beta.86

Date: 2026-06-29

Codename: **Preset Spine**

This is a structural Copilot settings hotfix on top of beta.85. It fixes the underlying preset drift: Copilot strength presets are now owned by shared backend model policy and exposed through `/api/ai-settings`, instead of being hard-coded independently in the React UI.

## Release Position

Release as:

```text
v1.0.0-beta.86
```

Tag target / deployed commit:

```text
d6b9f99 Centralize Copilot strength presets
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.85

- Copilot strength presets moved to `shared/model-policy.mjs`.
- `/api/ai-settings` now returns `copilotModelPresets`.
- React Settings and the command-panel Copilot quick switch render backend-provided presets.
- The frontend no longer owns a separate `COPILOT_MODEL_PRESETS` array.
- Current presets are all OpenAI-direct:

```text
Low     -> openai-direct / gpt-4o-mini
Medium  -> openai-direct / gpt-5.4-mini
High    -> openai-direct / gpt-5.4
Highest -> openai-direct / gpt-5.5
```
