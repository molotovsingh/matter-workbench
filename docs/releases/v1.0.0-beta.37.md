# Matter Workbench v1.0.0-beta.37

Date: 2026-06-24

This is a Beta 3 Matter Assistant composition hardening release. It keeps the
beta.36 GPT 5.5 Copilot preset and folds the later assistant-rail layout slices
into one tagged, deployed checkpoint.

## Release Position

Release as:

```text
v1.0.0-beta.37
```

Tag target / deployed commit:

```text
3b60c96 Anchor assistant composer at rail bottom
```

The tag points to the exact code installed on the DigitalOcean beta VM.

This release note is recorded in a later documentation commit on `main`; the
running product code remains the tagged deployed commit above.

Meaning:

- Beta 3 remains the accepted private-cloud beta line;
- the deployed product remains the React-only private beta with runtime DB
  storage;
- the Matter Assistant rail no longer duplicates the full Copilot answer pane;
- the Copilot thread now owns the usable middle rail space;
- titlebar controls stay in the editor column instead of stealing assistant-rail
  height;
- the `Skill | Ask | Research` composer now sits at the bottom of the rail with
  Recent Activity collapsed by default;
- Copilot provider/model routing remains `openrouter / openai/gpt-5.5` for the
  transient Copilot route.

## Included Since beta.36

Assistant rail hardening after the beta.36 model-selector checkpoint:

- removed the duplicate top-of-rail full-answer pane so the thread stays the
  single visible conversation surface;
- let the Copilot thread flex to the available assistant-rail height;
- moved titlebar controls and compact release/workspace chrome out of the
  assistant rail;
- anchored the assistant composer at the bottom of the rail;
- collapsed `Recent activity` by default while keeping the existing private-beta
  feedback entry unchanged;
- updated rail-layout and feedback-order tests to match the hardened structure.
