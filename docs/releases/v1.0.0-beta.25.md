## Not Promised

This release still does not promise public SaaS signup, self-service password
reset, unsupervised legal reliance, external object storage, hard credit
enforcement, hosted DB workers, or a multi-region production posture. It is a
private-cloud beta for trusted testers and supervised operators.

The upload preflight guard is a first barrier against oversized browser
requests. It does not yet turn large matters into resumable, parallel,
server-side ingestion jobs; that remains future intake-service work.

## Operator Notes

If testers report upload failure after this release, first check whether the
failure happened before submit, during server upload, during extraction, or
during later preparation. These are separate layers now:

1. browser upload preflight;
2. upload API / multipart handling;
3. intake planning and custody registration;
4. extraction and source labeling.

If rollback is needed, use the ops-pack rollback plan generated for this
release or deploy the recorded rollback candidate `3ca34ff`.
