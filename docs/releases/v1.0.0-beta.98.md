## Included Since beta.97

- Extracted the duplicated New Matter/Add Files unfinished-upload card into `UploadSessionRecoveryCard`.
- Centralized create-matter and add-files session start/resume/upload/commit flow in `runUploadSessionWorkflow()`.
- Removed no-op catch/rethrow blocks from the session workflow.
- Kept the beta.96 behavior unchanged:
  - unfinished durable session card remains visible;
  - re-selecting the same paths/sizes resumes the saved session;
  - successful commit clears the browser draft;
  - forgetting a draft best-effort cancels server-side session custody.

## Not Promised

This release intentionally changes no product workflow. It does not add chunked upload, new auto-queued preparation stages, or new recovery semantics beyond the already shipped durable whole-file retry/resume path.

## Remaining Limits

The next product-bearing slice should be scheduler ownership of more preparation stages, or chunked upload if very large individual files become the immediate blocker.

## Operator Notes

Use `v1.0.0-beta.98` for supervised testing. Roll back to `v1.0.0-beta.97` / `c9ed431` if the refactored upload recovery UI unexpectedly affects create/add-files behavior.
