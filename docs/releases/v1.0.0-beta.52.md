# Matter Workbench v1.0.0-beta.52

Date: 2026-06-25

Codename: **Boundary Stone**

This is a Beta 3 Skill Factory hardening release. It fixes brittle matter-context
handoff across sample generation, approval, and custom-skill creation, and keeps
internal context-packet language out of generated sample text.


The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.51

Skill Factory matter-boundary hardening:

- carries the explicitly selected matter into `create-skill` instead of relying
  on stale saved idea metadata;
- resolves runtime DB skill creation from the selected active matter before
  reading the DB-native matter context packet;
- aligns the React Skill Factory create path with the already-explicit sample
  generation path;
- treats active matter folder/name as equivalent for stale async guards;
- adds regression coverage for creating a skill from an idea whose saved
  `idea.matter` is stale/missing while the UI supplies the current matter.

Skill sample output hardening:

- strengthens the sample-output provider instructions so generated samples do
  not mention context packets, bounded context, evidence blocks, truncation,
  omission, max limits, or app/provider mechanics;
- post-processes generated sample markdown to replace internal context-packet
  language with user-facing matter-record language if the provider still emits
  it;
- adds regression coverage for leaked phrases such as `bounded context`,
  `available packet`, `packet excerpts`, `evidence blocks`, and `maxBlocks`.

matter boundary and sample text presentation.
