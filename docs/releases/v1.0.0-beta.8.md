# Matter Workbench v1.0.0-beta.8

Date: 2026-06-07

This is the private-VM release-marker and handoff-correction checkpoint.

It keeps the product behavior from `v1.0.0-beta.7`: React-only UI, local/private
runtime DB mode, durable local job-status evidence, private beta access gate,
operator evidence packs, and supervised beta boundaries.

The reason this is a new release marker is operational: the published
`v1.0.0-beta.7` tag already pointed at an older commit. We do not force-move
published release tags. `v1.0.0-beta.8` is the current checkout target for the
passed private VM beta state.

## Release Position

Release as:

```text
v1.0.0-beta.8
```

Meaning:

- the React shell remains the only product UI at `/`;
- runtime DB mode remains accepted for local/private beta operation behind the
  explicit runtime flags and safe runtime role;
- the private VM path has repeatable service, ops, security, recoverability,
  and RC-closure evidence;
- Playwright is now an explicit project tooling dependency for rendered browser
  acceptance;
- the RC closure pack default release label matches the current release marker;
- the beta remains private-network/supervised beta, not public SaaS.

## Included

- Everything from `v1.0.0-beta.7`.
- Release-marker correction from the stale published `v1.0.0-beta.7` tag.
- Updated `private-beta:rc-closure-pack` default release label.
- VM deployment docs that tell operators to install dependencies with
  `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm ci`, build React, and keep a system
  Chromium binary available for browser acceptance.
- Checked-in representative RC closure evidence for the latest passed VM state.
- Regression test coverage that catches RC release-label drift.

## Not Promised

This release does not promise:

- public hosted SaaS deployment;
- HTTPS/TLS termination;
- hosted multi-user auth/session middleware;
- cloud object storage;
- hosted durable worker recovery;
- unsupervised legal reliance.

The exact claim is narrower: the current private VM beta has a stable release
marker, repeatable handoff commands, rendered browser acceptance, and operator
evidence for recovery and security posture.
