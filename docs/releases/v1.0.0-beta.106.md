## Included Since beta.105

- Centralized runtime preparation stage-to-job mapping in `shared/runtime-preparation-jobs.mjs`.
- Reused the shared mapping from both:
  - `services/runtime-db-processing-worker-service.mjs`
  - `routes/matter-workflow-routes.mjs`
- Centralized helper behavior for:
  - queueable preparation-stage selection;
  - blocked preparation-stage selection;
  - active runtime preparation job statuses;
  - safe preparation-chain id segments.
- Consolidated duplicated React advisory-completion logic in `react-ui/src/lib/autoPreparationRunner.ts`.
- Added `test/runtime-preparation-jobs.test.mjs` to keep the shared mapping and helper behavior pinned.
- Preserved beta.105 behavior: runtime DB **Run needed preparation** remains backend-owned, React still polls `/api/jobs`, and local/filesystem direct execution remains the fallback.
