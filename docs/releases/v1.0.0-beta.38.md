# Matter Workbench v1.0.0-beta.38

Date: 2026-06-24

This is a Beta 3 UX hardening release for the Matter Assistant composer and the
Skills page. It keeps beta.37 assistant-rail composition and makes legal
workflows more actionable without requiring users to start from slash commands.

## Release Position

Release as:

```text
v1.0.0-beta.38
```

Tag target / deployed commit:

```text
9f45403 Make Skills page workflows actionable
```

The tag points to the exact code installed on the DigitalOcean beta VM.

This release note is recorded in a later documentation commit on `main`; the
running product code remains the tagged deployed commit above.

Meaning:

- Beta 3 remains the accepted private-cloud beta line;
- the deployed product remains the React-only private beta with runtime DB
  storage;
- the assistant composer supports multi-line questions while staying anchored at
  the bottom of the Matter Assistant rail;
- the Skills page now presents built-in workflows as an action table with a
  primary button and a visible Matter Assistant shortcut;
- shortcut education is additive: users can click the action button now and
  learn the shortcut over time;
- custom skill lifecycle and governance controls remain scoped to custom skills.

## Included Since beta.37

Matter Assistant composer:

- converted the command input to an auto-growing multi-line composer;
- preserved Enter-to-submit and Shift+Enter for new lines;
- kept the composer anchored in the bottom rail;
- added regression coverage for the multi-line composer behavior.

Actionable Skills page:

- changed the page headline from an informational catalog to `Run or build legal
  workflows`;
- replaced the collapsed built-in workflow catalog with a visible action table;
- added columns for `Skill / workflow`, `What it helps you do`, `Best next
  action`, and `Shortcut`;
- wired built-in workflow buttons through the same command route used by Matter
  Assistant;
- kept visible shortcuts so users learn the command rail without being forced to
  start there;
- kept custom-skill run, pause, archive, restore, and delete controls separate
  from app-managed built-ins.

## Not Promised

This release does not add new workflow engines, new Research semantics, durable
Copilot memory, or new custom-skill lifecycle states. The Skills page is more
actionable, but the underlying workflow safety and governance boundaries are
unchanged.
