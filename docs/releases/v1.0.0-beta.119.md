## Included Since beta.118

- Centers generic rendered Markdown previews in an A4-style document page.
- Adds paper-like padding, border, radius, and subtle shadow to the Markdown preview.
- Justifies paragraph text at comfortable widths for a more formal legal-document feel.
- Keeps narrow/mobile previews left-aligned to avoid awkward word spacing.
- Keeps headings, tables, code, and the specialized Case Timeline/List of Dates preview outside the paragraph-justification change.

## Behavior

Generic `.md` matter documents, including saved Filing and Procedural Posture Diagnosis documents, now open in a document-style page frame rather than a full-width app panel. Paragraphs are justified on normal desktop widths and switch back to left alignment on narrow screens.

The change is CSS-only for generic Markdown previews. It does not affect artifact storage, Markdown parsing safety, or the specialized Case Timeline/List of Dates preview.

## Not Promised

This release does not add page-size controls, edit mode, print/export features, real physical A4/A3/A2 sizing, syntax highlighting, or changes to legal output. It only applies an A4-style page frame and paragraph justification to generic rendered Markdown previews.

## Operator Notes

Use `v1.0.0-beta.119` for supervised testing. If justified paragraphs look awkward on a specific document, test the same document at a narrow width; the responsive fallback should return paragraphs to left alignment.
