# Matter Workbench v1.0.0-beta.34

Date: 2026-06-24

Codename: **Thread Needle**

This is a Beta 3 Copilot thread-helper hardening release. It keeps beta.33
interaction receipts and extracts browser-local Copilot thread shaping into a
small tested helper, so future follow-up and receipt work does not keep growing
inside the main app shell.

## Release Position

Release as:

```text
v1.0.0-beta.34
```

Tag target / deployed commit:

```text
dc0eefd Extract Copilot thread helpers
```

The tag points to the exact code installed on the DigitalOcean beta VM.

Meaning:

- Beta 3 remains the accepted private-cloud beta line;
- the deployed product remains the React-only private beta with runtime DB
  storage;
- Copilot interaction receipts from beta.33 remain available;
- browser-local Copilot thread behavior is unchanged;
- thread append and bounded request-context shaping now live in
  `react-ui/src/lib/copilotThread.ts` with focused tests;
- no durable memory, new artifact, or evidence-rule change is introduced.

## Included Since beta.33

Copilot thread helper refactor:

- extracted visible-thread append logic and bounded conversation request shaping
  from `App.tsx` into `react-ui/src/lib/copilotThread.ts`;
- reused the shared `CopilotThreadTurn` type from the helper in the command
  panel;
- added helper tests for visible-thread length and request-context bounds;
- preserved the rule that bounded follow-up context is for reference resolution
  only and not evidence.

## Not Promised

This release is a refactor/hardening release. It does not add durable Copilot
memory, persisted chat threads, receipt analytics, or new user-facing Research
behavior.

## Operator Notes

If the assistant thread behaves unexpectedly, first check whether the matter was
switched or New Task was pressed; both intentionally clear the browser-local
thread. If rollback is needed, deploy the recorded rollback candidate `1a72422`.
