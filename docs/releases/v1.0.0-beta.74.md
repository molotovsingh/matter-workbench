# Matter Workbench v1.0.0-beta.74

Date: 2026-06-28

Codename: **Upload Atlas**

This is a Beta 3 tester-feedback upload release. It raises the private beta browser/server upload batch cap from 96 MB to 256 MB, exposes the file-count limit to the React app, and makes the upload-limit guidance visible before testers submit voluminous records.

## Release Position

Release as:

```text
v1.0.0-beta.74
```

Tag target / deployed commit:

```text
51f4081 Raise beta upload batch limits
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.73

Tester feedback addressed:

- `feedback_6083383d-0f4a-40ea-8475-e113f3c2354e` — “Maximum limit of Files that can be uploaded”;
- `feedback_76b8fb63-e60d-4c94-8ed9-9cead8c2c186` — “Tried adding voluminous file. Not working. Not every document can be 4-5 pages”;
- `feedback_ee11a3a0-88b4-4ba6-903e-aaf0d30de86c` — “Make sure heavy files get processed too. Increase the Mb”.

Changes:

- private VM default upload batch limit is now 256 MB instead of 96 MB;
- browser upload preflight now uses the same 256 MB beta stability cap;
- upload config now exposes `maxUploadFiles` as well as `maxUploadBytes`;
- multipart uploads now take a configurable `maxUploadFiles` limit and return a clearer `upload.too_many_files` message;
- New Matter and Add Files now show visible upload-limit guidance before submit;
- oversized-batch copy now states the selected size, current limit, and practical batching advice for very large PDFs;
- file-count preflight blocks batches above the configured count before submit.

## Not Promised

This release does not make uploads unlimited, does not guarantee successful extraction/OCR for every very large or scanned document, does not speed up long-running extraction jobs, does not add Google Drive import, and does not raise the supported private beta batch above 256 MB.

For larger records, testers should upload in batches and then run preparation steps. Processing speed and long-wait feedback remains a separate active item.

## Operator Notes

When testers ask about upload limits, use simple wording: the current private beta supports up to 256 MB and 5,000 files per upload batch. A large matter can still be built across multiple batches using Add Files.
