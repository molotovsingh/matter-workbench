Codename: **Refresh Wheel**

This is a Beta 3 Skill Factory post-create UX hardening release. It makes a
newly created custom skill immediately visible and runnable after approval.

## Included Since beta.52

Skill Factory post-create flow:

- adds an app-wide Skills refresh signal after custom-skill creation;
- reloads the Skills page when that signal changes, even if the user was already
  on the Skills tab;
- reloads Matter Assistant command suggestions so the new slash shortcut becomes
  available without a browser refresh;
- switches the main pane to Skills and sets breadcrumbs to `Skills` after
  creation;
- updates the created-state copy to show that the new skill is in `Your Skills`,
  can be run on any selected matter, and can also be triggered from Matter
  Assistant by shortcut.

Clarified current naming behavior:

- the user can influence the name through the Skill Factory interview's
  `What would you like to name this skill?` question;
- the final `title` and `slash` are still produced by the authoring step and
  normalized by the app;
- this release does not add a final rename/shortcut review step before creation.

## Not Promised

This release does not add a final editable skill-name or slash-command approval
step. It only hardens visibility and refresh behavior after the existing creation
flow succeeds.
