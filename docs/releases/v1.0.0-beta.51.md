# Matter Workbench v1.0.0-beta.51

Date: 2026-06-25

This is a Beta 3 Skill Factory runtime DB hotfix release. It fixes approval of a
new sample when a prior sample for the same skill idea is already approved.

Release as:

```text

```

```text

```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.50

Runtime DB Skill Factory sample approval hotfix:

- fixed runtime DB sample approval so approving a new current sample first clears
  any prior approved sample for the same idea;
- avoids the Postgres partial unique constraint error
  `skill_samples_one_approved_per_idea` when regenerating/approving another
  sample;
- aligns runtime DB behavior with the local JSON skill-samples service, where
  only one sample remains approved per idea;
- keeps stale and not-found approval diagnostics stable;
- adds regression coverage for ordered clear-then-approve SQL.

Release hygiene additions since beta.50:

- added `npm run release:position-check` to verify release tag/note/current
  pointer agreement;
- added the Skill Interview owner test note at
  `docs/skill-interview-owner-test-plan.md`.

## Not Promised

This release does not change sample generation quality, Skill Factory approval
policy, custom-skill prompts, model routing, or UI layout. It only fixes runtime
DB approval state when replacing an approved sample.
