# Matter Workbench v1.0.0-beta.12

Date: 2026-06-16

This is the current Beta 3 private-cloud checkpoint.

It keeps the Beta 3 product surface from `v1.0.0-beta.11` and formalizes the
DigitalOcean deployment at commit `f4375df`, after the runtime DB query path was
made easier to reason about and re-use.

## Release Position

Release as:

```text
v1.0.0-beta.12
```

Tag target:

```text
f4375df Extract runtime DB query helper
```

Meaning:

- the deployed private beta runs from the React-only product UI;
- runtime DB storage remains the accepted deployed beta path;
- DigitalOcean deployment uses the repeatable `private-vm:rsync-deploy` flow;
- the release badge is served from deployment metadata;
- the app and mothership services are both expected to be active;
- VM deploy applies runtime DB migrations before activation;
- VM deploy runs a service check and rendered UI hardening pass before the
  release is treated as usable.

## Included Since beta.11

- Release badge and release date surface for testers.

- Stronger telemetry/citation checks.
- Shared matter identity policy and upload path policy.
- Safer rollback and telemetry retry behavior.
- Runtime DB migrations integrated into VM deployment.
- Stale auto-preparation UI suppression.
- Sequential upload-overlap hashing.
- Normalized provider quota errors for Skill Factory.
- Shared runtime DB query helper used by the storage service.

For a full release-confidence rerun, use `private-beta:rc-closure-pack`. The RC

## Not Promised

This release still does not promise public SaaS signup, self-service password
reset, unsupervised legal reliance, external object storage, or a multi-region
production posture. It is a private-cloud beta for trusted testers.
