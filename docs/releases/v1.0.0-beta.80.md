# Matter Workbench v1.0.0-beta.80

Date: 2026-06-29

Codename: **Timeline Lantern**

This release promotes the neutral chronology surface to **Case Timeline** and deploys the first product-wired **Filing and Procedural Posture Diagnosis** workflow. It also suppresses the global top readiness banner when the only degraded readiness check is Matter Assistant availability.

## Included Since beta.79

Legal workflow:

- user-facing neutral chronology is now presented as **Case Timeline**;
- internal `/create_listofdates` command and `10_Library/List of Dates.*` artifact paths remain stable;
- Case Timeline prompt/schema copy is record-neutral rather than client-favourable;
- generated chronology Markdown now renders `# Case Timeline`;
- `/the_story` remains based on the stable List of Dates artifact path.

Case Analysis:

- added automatic **Filing and Procedural Posture Diagnosis** after Case Timeline and Matter Story;
- writes diagnosis artifacts under `20_Workshop/Case Analysis/`;
- diagnosis is provisional until lawyer confirmation;
- Matter Overview surfaces a Case Analysis posture card with confirm, correct, and not-sure actions;
- confirmation/correction history appends to Case Analysis Q&A;
- runtime DB storage mode can run and persist the diagnosis through DB-native custody.

Readiness UX:

- assistant-only readiness degradation no longer shows the global top banner;
- non-assistant workspace/service readiness problems can still show the top banner;
- user-facing readiness copy remains sanitized and does not expose provider/model/key details.

## Not Promised

This release does not rename internal `/create_listofdates` routes or `10_Library/List of Dates.*` files. It does not convert Case Timeline into advocacy work product. Client-favourable framing remains reserved for future Matter Workbench Advocacy List of Dates / Case Analysis outputs.

The posture diagnosis is provisional and lawyer-review-gated. It should not silently authorize downstream drafting when the lawyer marks the posture as not sure or corrects it.

Matter Assistant provider/account health is still external runtime configuration. The service check currently reports assistant readiness as degraded, but the workspace remains usable and the top banner is suppressed when that is the only readiness issue.
