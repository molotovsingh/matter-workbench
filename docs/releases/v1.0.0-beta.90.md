# Matter Workbench v1.0.0-beta.90

Date: 2026-06-29

Codename: **Quiet Query**

This is an operator-only hotfix on top of beta.89. It narrows the canned mothership investigation helper so text/user misses do not report unrelated signals or matter-health rows.

## Release Position

Release as:

```text
v1.0.0-beta.90
```

Tag target / deployed commit:

```text
b970114 Narrow mothership investigation signal matches
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.89

- `mothership:investigate` now requires signal rows to actually match text queries.
- User-only investigations with no matching feedback no longer attach generic signal matches.
- Latest matter health is no longer shown when there is no matter hint.
- Added regression tests for text-only misses and user-only misses.
