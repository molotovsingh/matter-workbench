# Matter Workbench v1.0.0-beta.79

Date: 2026-06-28

Codename: **Column Compass**

This is a shallow UI polish release after the beta.78 official handoff checkpoint. It widens the left navigation rail so the three-column app shell feels more balanced against the main workspace and Matter Assistant rail.

The release does not change custody, auth, upload, database, legal workflow, or model behavior.

```text
v1.0.0-beta.79
```

Tag target / deployed commit:

```text

```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.78

Tester-facing polish:

- the left navigation rail is wider in desktop layout (`220px` -> `260px`);
- the archive-confirmation expanded rail has matching extra room (`340px` -> `360px`);
- the existing responsive collapsed sidebar behavior is unchanged;
- the Matter Assistant rail remains resizable and unchanged.
