# Matter Workbench v1.0.0-beta.30

Date: 2026-06-24

Codename: **Escalation Compass**

This is a narrow Beta 3 Research UX hardening release. It keeps beta.29 Copilot
Research mode and adds the Ask-to-Research escalation that was planned in the
Research mode contract.

## Release Position

Release as:

```text
v1.0.0-beta.30
```

Tag target / deployed commit:

```text
ebf9d46 Add Ask to Research escalation
```

The tag points to the exact code installed on the DigitalOcean beta VM.

Meaning:

- Beta 3 remains the accepted private-cloud beta line;
- the deployed product remains the React-only private beta with runtime DB
  storage;
- `Skill | Ask | Research` remains the explicit command mode model;
- Research mode from beta.29 remains enabled on the VM;
- Ask mode now detects likely public-legal-research questions and asks the user
  to choose between a matter-record answer and Research public sources;
- Ask still does not silently browse the web.

## Included Since beta.29

Ask-to-Research UX hardening:

- added a React-side research-intent helper for legal-research-shaped questions;
- added an explicit choice panel:

```text
This may need public legal research.

[Answer from matter record] [Research public sources]
```

- routed the first choice to `/ask ...` and the second to `/research ...`;
- kept explicit `/ask` and `/research` commands deterministic;
- added regression tests proving Research is suggested rather than silently
  triggered.

## Not Promised

This release does not add durable Copilot memory, persistent conversation
threads, or automatic web browsing for every Ask question. Research remains an
explicit user choice. Research answers still require lawyer verification before
relying or filing.

## Operator Notes

If users expect Ask to browse automatically, remind them that the app now asks
for confirmation before using public sources. If Research fails, ordinary Ask
remains available as a matter-record-only fallback. If rollback is needed,
deploy the recorded rollback candidate `8766df4`.
