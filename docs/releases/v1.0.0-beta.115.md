## Included Since beta.114

- Fixed Matter Overview preparation rows so the active row shows **Running** while its preparation job is queued or running.
- Applied this to the saved Filing and Procedural Posture Diagnosis row, so it no longer keeps saying **Not started** while diagnosis is already working.
- Added row-level progress detail from the active preparation job, such as server queued/running status.
- Kept existing preparation plan currentness logic intact for idle rows; the overlay applies only to active/failed preparation progress.

## Behavior

When a user starts **Run saved Procedural Diagnosis** or another row-level preparation action, the Matter Preparation row now derives visible status from the active preparation run/job in addition to the persisted preparation plan.

During the run, the row status pill shows **Running** and the row displays the job detail. After the job finishes and the matter refreshes, the row returns to the saved artifact/currentness state from the preparation plan.
