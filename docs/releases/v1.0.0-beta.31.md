# Matter Workbench v1.0.0-beta.31

Date: 2026-06-24

This is a Beta 3 Copilot Research observability and UX hardening release. It
keeps beta.30 Ask-to-Research escalation and adds a browser-local Copilot thread,
Research-specific failure recovery copy, stronger public-source display, and
Mothership signal capture for Research outcomes.

## Release Position

Release as:

```text
v1.0.0-beta.31
```

Tag target / deployed commit:

```text
6ca60e8 Capture Research route signals
```

The tag points to the exact code installed on the DigitalOcean beta VM.

Meaning:

- Beta 3 remains the accepted private-cloud beta line;
- the deployed product remains the React-only private beta with runtime DB
  storage;
- Copilot remains stateful for conversation display but stateless for evidence;
- the visible Copilot thread is browser-local and in-session only;
- Research failures now use Research-specific recovery copy;
- Research public sources are displayed with stable `WEB-000N` IDs;
- Research success/failure is captured as Mothership/client signals from both
  the browser path and the backend route.

## Included Since beta.30

Copilot/Research UX hardening:

- added a visible in-session Copilot thread for Ask and Research turns;
- kept the thread browser-local and resettable, with no durable memory or matter
  artifact writes;
- improved Research failure copy so provider/billing/quota failures collapse to
  a Research-specific recovery message;
- kept Research selected after choosing public-source Research from the Ask
  escalation panel;
- displayed public source labels with stable `WEB-000N` IDs.

Research source/citation hardening:

- included public source IDs referenced in answer prose in the returned public
  source list;
- continued dropping unsupported/invented public source IDs;
- added tests covering prose-referenced `WEB-000N` IDs.

Mothership/observability hardening:

- added client-side Research signals for returned and failed Research attempts;
- added backend-route Research signals for API success and failure;
- verified queued Research signals sync to the local mothership endpoint.

## Not Promised

This release does not add durable Copilot memory, persistent conversation
threads, or backend use of previous turns as evidence. The visible thread is
only an in-session UX improvement. Research still requires lawyer verification
before relying or filing.

## Operator Notes

If Research appears to fail, check the Mothership/client signal lane for
`copilot_research.*` events and distinguish:

1. Exa/web-source search failure;
2. answer synthesis/provider failure;
3. no useful public sources;
4. matter context missing;
5. user choosing Ask instead of Research.

If rollback is needed, deploy the recorded rollback candidate `8df8e03`.
