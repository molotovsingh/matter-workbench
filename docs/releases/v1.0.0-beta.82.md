# Matter Workbench v1.0.0-beta.82

Date: 2026-06-29

Codename: **Assistant Signal**

This is a hotfix on top of beta.80. It restores the Assistant readiness warning because Assistant availability is a real service-health signal, while keeping provider/account backend details out of user-facing Ask answers.

## Release Position

Release as:

```text
v1.0.0-beta.82
```

```text

```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.80

- removed assistant-only top-banner suppression;
- restored Assistant readiness as a degraded readiness warning on login and in service checks;
- kept Ask/terminal error formatting sanitized so backend messages such as `User not found` render as neutral Assistant unavailable copy;
- preserved beta.80 Case Timeline and Filing and Procedural Posture Diagnosis changes.

A transient beta.81 deployment briefly treated Assistant outage as optional workspace readiness. That posture was rejected and superseded by this release.
