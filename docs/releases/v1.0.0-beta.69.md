# Matter Workbench v1.0.0-beta.69

Date: 2026-06-28

This is a Beta 3 archive UX polish release. It makes reopening archived matters explicit and visible in `All matters → Archived`.

## Release Position

Release as:

```text
v1.0.0-beta.69
```

Tag target / deployed commit:

```text
89b1dfa Make archived matter reopening explicit
```

The tag points to the exact code installed on the DigitalOcean beta VM.

## Included Since beta.68

Archived matter browser polish:

- `All matters → Archived` now shows a clear custody note: archived matters are closed from active work, not deleted;
- archived rows show the archived date when available;
- archived rows now include an explicit `Reopen` button instead of relying only on clicking the row;
- the UI continues to use legal workflow language: `Reopen`, not `unarchive`;
- reopening still preserves existing source files, generated artifacts, file IDs, and history.

## Not Promised

This release does not add permanent matter deletion, source-file deletion, retention-policy automation, legal-hold review, export-before-purge, restore/quarantine for individual source files, outbox publishing, or Kafka/broker integration.

## Operator Notes

After refreshing the browser, testers should see `All matters → Archived` with a short preserved-custody explanation, archived dates where recorded, and an explicit `Reopen` button. The first Archive click still opens the visible confirmation panel; the second `Confirm archive` click archives the matter.
