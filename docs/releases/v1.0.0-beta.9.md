# Matter Workbench v1.0.0-beta.9

Date: 2026-06-07

Codename: **Feedback Falcon**

This is the feedback-first tester handoff checkpoint for the private/local beta.

It keeps the product behavior from `v1.0.0-beta.8`: React-only UI,
local/private runtime DB mode, private beta access gate, rendered browser
acceptance tooling, operator evidence packs, and supervised beta boundaries.

The reason this is a new release marker is operational: after `v1.0.0-beta.8`,
the handoff docs were corrected to match the actual in-app feedback flow.
Testers should not be asked to manually export diagnostics or classify product
problems. They should use **Have a problem? Tell us what happened** first, and
operators should use Activity feedback before running deeper evidence packs.

## Release Position

Release as:

```text
v1.0.0-beta.9
```

Meaning:

- the React shell remains the only product UI at `/`;
- beta testers get the feedback-first handoff instructions;
- Activity feedback is the normal first intake for confusing, wrong, slow, or
  legally weak behavior;
- `private-beta:bug-evidence-pack` remains the deeper developer handoff tool,
  not the first thing a tester has to understand;
- the RC closure pack default release label matches the current release marker;
- the beta remains private-network/supervised beta, not public SaaS.

## Included

- Everything from `v1.0.0-beta.8`.
- Updated tester brief: use **Have a problem? Tell us what happened** first.
- Updated operator checklist: review Activity feedback and sync status before
  running deeper bug evidence.
- Updated bug-fix loop: start from the in-app feedback record when available.
- Updated bug evidence pack docs: use the pack after a feedback record exists,
  or when the app is unavailable and direct operator capture is the only path.
- Updated `private-beta:rc-closure-pack` default release label.

## Not Promised

This release does not promise:

- public hosted SaaS deployment;
- HTTPS/TLS termination;
- hosted multi-user auth/session middleware;
- cloud object storage;
- hosted durable worker recovery;
- unsupervised legal reliance.

The exact claim is narrower: the current private beta has a clear release
marker and a tester handoff path that matches the app's actual feedback intake.

## Operator Notes

Use this tag instead of `v1.0.0-beta.8` for private beta tester handoff. The
older tag is historical and should not be used as the current handoff target if
testers are receiving the feedback-first brief.

Before widening tester access, rerun:

```bash
npm run private-beta:rc-closure-pack
```

Treat any failed section as a release blocker until it is understood.
